# 主线与难点规划

这篇文章抓住一个迟来的变化：减轻丈夫杀死妻子情人的罪责，怎样扩展成减轻他杀妻的罪责。作者把这一步放回“体面男人该怎样维护家庭”的社会期待中解释。

1. 先拆开杀情人减责与杀妻减责，确定真正变化
2. 对照教材规则与1810年裁判，找出需要解释的一步
3. 追踪丈夫名誉、妻子身份与公共道德如何相连
4. 用不同材料和反对声音检验解释，保留传播证据的边界
