# 主线与难点规划

本文把“找得到”与“认得准”拆开测试：BRK2能读出很少的目标DNA，但近缘种干扰取决于引物和探针如何设计。

稀有物种难抓，取水提供了另一条取证路线。 → 同一份水里，为什么会有两种难题？ → 接着看qPCR怎样产生信号，才能理解干扰可以发生在哪里。

“有曲线”背后，既有DNA复制，也有荧光报告。 → 一个荧光信号要经过哪两道环节？ → 作者据此把物种区别放到不同环节，比较哪种设计更可靠。

多一道探针并不会自动消除近亲DNA的影响。 → 区别放在探针端，还是引物端？ → 先把设计放下，分别来看低模板测试与混样测试给了什么答案。

少模板时，同一浓度不同反应也可能有成有败。 → 低到每管两份，能找到多少次？ → 低浓度能检出之后，还须确认大量近亲不会把这份本领破坏。

单独不明显发光的近亲，仍可能在同管争用扩增资源。 → 为什么纯样好好的，混起来却变了？ → 设计必须回到具体物种与反应里测试，而不是选一个“错配最多”的数字就结束。

实验室认出DNA之后，还剩生态来源这一层。 → 最后怎样把检测结果用于监测？ → 整篇围绕一个朴素问题收束：既把稀少目标找出来，也查清信号是谁、从哪里来。
