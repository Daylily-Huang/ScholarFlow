# 主线与难点规划

能读出多种鱼的遗传痕迹。这篇先用海水eDNA列出鱼种，再与现场调查比较，并测信号多久会降到检测线以下。

要保护海鱼，先得知道调查名单漏掉了什么。 → 为什么改从水里找鱼？ → 下一步沿着一份真实水样走进实验室。

取到了水，鱼名还藏在不同物种混杂的碎片里。 → 一瓶水怎样变成一张名单？ → 有了名单，还要找参照判断它覆盖得怎样。

检出数本身还不能说明方法值得替代或补充什么。 → 15种鱼，表现究竟怎样？ → 名单够丰富之后，另一个问题浮出来：这些DNA真来自附近的鱼吗？

海流会搬运DNA，先得知道信号能存续多久。 → DNA多久会淡到读不出？ → 存续时间给了一个约束，但要换成空间范围，还少水流与稀释。

几天听起来短，海流在这期间却能搬很远。 → “很快降解”为何仍不能直接圈出本地？ → 把分子过程与现场记录接好，才能解释检测名单。

一张可用名单与一套成熟监测系统之间，还隔着几步。 → 读完以后，哪些事情已经解决？ → 整条主线因此是：从水中取痕迹→形成物种名单→检查覆盖→研究信号存续和来源→确定下一步监测验证。
