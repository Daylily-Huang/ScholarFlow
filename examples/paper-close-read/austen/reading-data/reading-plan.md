# 主线与难点规划

这篇《劝导》研究把安妮的变化读成一条“声音与认识”的线：她起初被忽视，只能观察、旁听和在心里说话；后来，她的判断力被看见，自己的观点也能公开说出来。

1. 由 nobody 的措辞和暂居处境，看她如何被忽视
2. 由旁听与身体观察，理解她为何敏锐又会误判
3. 由具体措辞与叙述视角，进入旁人听不到的心事
4. 由危机行动和公开发言，看内在判断怎样获得分量

## 演示安排

### 只看这几个词：房间怎样变成她的感受

理解障碍：seemed 与重复的 full 怎样让读者贴近安妮？

演示对象/变化：text_focus；先读房间和声音：这是会面发生的社交环境。 → 把目光停在 seemed：这里呈现的是安妮的感受，非中性盘点。 → 再听 full 的重复：拥挤和声响被叠加，回应她重逢时的紧张。

插入原文：b-123d95f1f9c630ea-1；导读对应章节也直接嵌入。

短语由论文引自《劝导》1994年版第58页；此处分析措辞，不把该句自动判为自由间接话语。

### 同样是旁听，为什么这次让两人走到一起

理解障碍：消息经过谁、被怎样理解，如何改变安妮与温特沃思的关系？

演示对象/变化：communication；温特沃思与路易莎说话，安妮在旁听到；她据此猜测婚姻意图。 → 场景改到白鹿旅店：安妮向哈维尔表达立场，温特沃思旁听。 → 温特沃思把听到的立场与自己的感情接起来，以书信向安妮明确回应。

插入原文：b-a42eeac03f61764f-1；导读对应章节也直接嵌入。

第二位人物随场景切换：第一步是路易莎，后两步是哈维尔；点的运动表示信息传递，不模拟人物实际走位。

nobody从具体词句与家庭处境解释；home区分居所与归属；聚焦者、叙述者、直接内心话、自由间接话语分清。人物误判与强情绪可修正单向成长读法。
