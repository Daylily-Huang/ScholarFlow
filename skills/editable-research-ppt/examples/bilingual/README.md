# 双语与内容容量样板（开发候选）

三份均为两页合成数据样板，不是真实论文、研究区或实验结果。PPT内文字、图表/工作簿、表格、框图保持原生。预览是Windows PowerPoint16的实际导出，不是生图。未验证Mac/WPS显示。

- [学术分享 / 蓝白朱红](academic.pptx)：四联数据图、超过38字符的英文标题和双语观测说明；6张原生图表。
- [课程作业 / 靛紫芥黄](coursework.pptx)：环形研究框架、原生表格与分析进展；1张原生图表。短术语同一行中英配对。
- [实验进展 / 松绿米白](progress.pptx)：数据核对表、实验分组和时间轴；无图表，因此只验证文字/移动，未声称工作簿修改。

生成输入在assets/examples/bilingual-*.json。字号与原版式保持一致，新增17px副标题行；长正文需选合适区域或拆页。validation.json绑定样板和预览哈希；只证明所列实机检查，不代表所有场景/配色/版式组合均已验证，也不等同最终商用验收。
