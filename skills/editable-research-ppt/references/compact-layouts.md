# 已批准紧凑版式与四套新配色（v1.6）

用户于2026-10-23明确采纳四套配色，并仅选择合订候选稿第2、4、5、8、9、10页。批准文件哈希与页码在 `assets/templates/compact-bindings.json`。随包原生库只保留这六页；不将其他候选页作为新模板收录。原有 L1–L20 不变。

| --- | --- | --- |
| 2 | `L22 / fraction` | 中置分数公式、上下两个对比图及计算解释 |

每个家族的 `default` 分别对应 sidebar、fraction、lanes；通常显式写 variant 便于审阅。场景仍取顶层 `scenario`，同一结构可以服务不同学科与汇报场景，不强制课程只能用比较页。

配色新增 P7 赭橙米白、P8 深蓝香槟金、P9 孔雀青白、P10 黑白朱红；P1–P6仍可选。所有主题支持 `light` / `solid`：实底保留深色容器与白字，浅底把主色实填容器与对应文字转换成浅底深字。配色不能覆盖真实论文原图的语义颜色。

## 输入和内容替换

从 `assets/examples/compact-approved.json` 取所需页，不照搬六页页序。每页必须提供 `title`、当前变体完整的 `texts`、`sources`；图表页还提供 `charts`，进展页提供 `table`。`texts` 的语义键可在该示例与 bindings 中逐项对应，缺字段、额外字段或未知变体报错，防止静默留下示例文字。

图表使用现有 line / bar 字段与非空 source，附可编辑工作簿；单图或双图、系列数由所选变体决定。可以更换类别、序列、数值和坐标范围，不能将图表改为截图。每个图表工作簿独立；公式、指标文字、图例文字、解释与表格也独立，改数据后须同步这些可见文字，生成器不推断科研公式或跨对象联动。

进展表当前固定4行×3列（含表头）；三阶段任务流程的几何和编号固定。多于三阶段时拆页，不能把额外内容静默丢掉。字段超出实际区域时报错，不自动缩小字号。正文需要换行时显式插入换行并检查高度。

这些变体不是论文原图槽位：不接受 image、figures、composition 或 title_translation。需要完整论文图、原表、地图、双语标题时选已有相应版式；一套稿可以混用。正式输入的 materials.papers 清单及原图硬指标仍然生效，不能用这些合成示例代替论文证据。

## 固定比例与素材

画布1280×720，标题36px（27pt）、正文20–21px（15–15.75pt）、分区标题主要23px、图表标注至少17px、页脚14px、左右32px。大数值可保留60px。原生模板是这些变体的实际几何来源，compact_typography记录已批准标准；旧版fill_styles的42px标题规则不应用到这些模板。

联网上的六个Lucide SVG已经转换成可改色、移动、缩放的原生轮廓组，源文件与许可在 assets/icons/lucide/。只有内容仍匹配时才保留相机/实验类图标；换学科先按联网素材优先规则寻找相关素材，或去除无关图标后实机核验，不把已缓存图标当成“本次已经联网搜索”的证明。原生路径可取消组合编辑；任意复杂SVG不保证能相同转换。必要边框、箭头和数据图仍以原生对象实现。

## 生成与验证

```console
python scripts/generate.py --input assets/examples/compact-approved.json --output compact.pptx
python scripts/audit.py compact.pptx --strict
```

示例 palette_showcase 仅为一次展示多个配色，正常整套稿仍使用一种主配色与填充。修改内容后再次核对公式、图表、指标、图注、来源以及阶段/表格一致性，再在目标软件渲染。原生可编辑性不代表另一台电脑字体和软件显示完全一致。
