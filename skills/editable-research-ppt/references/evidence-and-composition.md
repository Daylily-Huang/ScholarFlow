# 原图、版式变体与整套节奏（v1.3）

## 原图是硬性验收项

只要用户提供或本次选用的论文中存在与汇报相关的图表，正式成稿必须包含直接从该论文 PDF 裁出的完整图表。数据展示和背景介绍都适用；不能全部使用重新绘制、合并整理或 AI 生成的图替代。多篇论文作为主要证据时，每篇有相关图表的论文至少有一幅原图进入成稿，而不是随便放一张无关图过关。

- 先核对用户全部资料，建立 `materials.papers` 清单；论文未取得、图表无法清楚裁取或来源无法核实，说明缺项，停在待审稿，不伪造“已通过”。
- 原图内文字、面板次序、颜色、坐标、单位、图例、统计标注和结果不改动、不重组。完整裁图允许排除周围正文与空白；不可遗漏理解图表所需的面板或说明。论文表格同样直接裁取。
- 即使有源数据，也不因“可编辑”而默认重绘。只有用户明确要求时才可另做改绘版，注明改绘，并保留原图对照；不能以改绘满足原图硬指标。
- 用户自己的结果图同样直接嵌入；仅有数据而没有现成图时才生成可编辑原生图表。没有提供论文的实验进展允许 `materials.papers: []`，不得为满足形式添加无关论文。
- 完整原图是独立图片，可移动、等比例缩放和替换；图内曲线、文字不承诺逐项可编辑。页内说明、框图及新增标注保持原生对象。

清单示例（路径相对于输入 JSON）：

```json
{
  "demo": false,
  "materials": {
    "papers": [
      {"id": "paper-a", "path": "materials/paper.pdf", "figure_status": "relevant"}
    ]
  }
}
```

`figure_status` 仅可为 `relevant`、`none`、`unavailable`。`none` 必须给出已核对的 `reason`；`unavailable` 阻止正式生成。生成器不能知道被遗漏的附件，助手必须把用户实际提供的论文全部列入清单，不能把漏填当成没有论文。

## 直接裁图与核对

使用 `scripts/crop_paper_figure.py` 从 PDF 页面按坐标直接渲染 PNG。PDF 裁图额外需要可选依赖 PyMuPDF；PPT 生成仍只需要 Python 标准库。

```console
python scripts/crop_paper_figure.py --pdf materials/paper.pdf --output figures/fig2.png --page 5 --bbox 45 100 550 600 --paper-id paper-a --figure "Fig. 2" --caption "图 2  原文图题或忠实简注" --source "真实作者，年份，Fig. 2"
```

页码从 1 开始，矩形为 PDF 页面坐标 `[左, 上, 右, 下]`，单位为 point。工具同时写出 `.json` 溯源记录。**先查看完整 PDF 页面和裁图**，确认完整、清晰且与当页论点相关，再把记录中的 `verified_complete` 改为 `true`；不得批量默认声称已核对。也可在已核对矩形后使用 `--verified-complete`。

把溯源记录放入页级 `figures` 列表；`path` 可改成相对输入文件的路径。生成器核验 PDF/PNG 哈希、页码、图号、可见图注、来源和实际使用位置。审计器继续检查嵌入的原图字节、滤镜和二次裁切。**哈希只证明文件一致，不能替代人工对图表完整性、来源真实性与科学含义的核对。**

## 新增六种版式：L15–L20

复制 `assets/examples/evidence-layouts.json` 或 `evidence-variants.json`。这些示例使用随包合成测试 PDF，不是真实论文；不得把示例结论用于正式研究。所有新内容页支持 `title`、`takeaway`、`sources`、`navigation`。

| 版式 | 使用时机 | 内容字段 | 变体 |
|---|---|---|---|
| L15 论文导读 | 一篇论文的问题、设计、关键证据 | `figures` 恰好一幅完整图；`sections` 1–3 条 `{title,body}` | 默认图在右；`figure_left` |
| L16 大图讲解 | 核心证据值得单页讲清 | 同上；`full_width` 不需要 `sections` | 默认图在左；`figure_right`、`full_width` |
| L17 全貌与局部 | 密集图表、地图或局部结果 | 一幅 `figures`；1–2 个 `zooms: [{label,rect}]` | `detail_left` |
| L18 地图采样 | 研究区、样点与调查安排 | 一幅原地图；`sections` 说明采样设计 | `map_right` |
| L19 分组时间轴 | 实验分组与观测时点 | `times` 2–6 项；`groups: [{name,sample,events}]`；`measurement` | 默认三组；`two_groups` |
| L20 文献矩阵 | 比较研究设计、发现与解释条件 | `matrix` 四列，表头＋1–4 行；`sections` 1–3 条 | `table_full` |

`zooms.rect` 是原图归一化坐标 `[左,上,右,下]`，取值 0–1。放大窗必须使用与全貌完全相同的图片，使用 PowerPoint 原生裁切保留可调整性；始终保留未裁切的全貌与来源。放大窗是辅助阅读，不能代替完整原图，也不能产生不存在的数据。

旧版式增加的变体不另计为新布局：

- L2/L3/L4/L8/L9/L10/L11 的 `original_figure`：保留该页的内容用途，改用完整原图满宽呈现；输入 `figures` 一幅即可，不再强填旧卡片/图表字段。
- L3/L9 的 `swap_columns`：对调两栏，内容随整栏移动。
- L11 的 `swap_rows`：对调上下两排结果面板。
- 原生图表旧版式适用于仅有原始数据、没有现成结果图，或用户明确要求额外重绘的情况。

## 固定组件

新图像页自动生成独立可编辑的图号/图题、来源文本。L17 自动生成可编辑放大框和编号。新内容页支持 `navigation: {"labels":["背景","方法","结果","讨论"],"active":2}`（1–6 项，`active` 从 0 开始），放在页底固定区域；也可文档级定义并逐页覆盖。

所有版式可显式加入 `components`，不会把文字烘焙进原图：

```json
[
  {"type":"figure_number","text":"图 2","box":[32,600,80,28]},
  {"type":"caption","text":"简短图题","box":[120,600,650,28]},
  {"type":"source","text":"作者（年份），Fig. 2","box":[32,632,800,24]},
  {"type":"zoom_frame","box":[200,220,180,120]},
  {"type":"number","text":"①","box":[160,220,30,28]},
  {"type":"navigation","text":"关键结果","active":true,"box":[820,688,140,24]}
]
```

坐标按 1280×720；示例位置不是所有版式的空白区。放置前检查实际页面，避开原图坐标和图例；不得把组件堆到已有页脚、图注或正文上。颜色继承当前配色，图内数据色彩不随模板变化。

## 主次、边界、图注与整套节奏

- 重要证据使用约 65%–100% 内容宽度；真正比较时才分栏。不能为凑模板把主图压到小卡片里。
- 图片只等比完整适配，不拉伸、不填充裁边；原图四边完整，边框贴实际图片边界。图注在图下，来源紧邻图注；不把来源缩小后塞进图内空白。
- 内容过多先拆页或用“全貌＋局部”，不缩小字号硬塞。新图注 20px、来源 17px、正文 21–25px、标题 42px、左右边距 32px。
- 在逐页计划中记录“本页论点／证据／layout／variant／主图占比”。按论证交替使用导读、大图、比较、流程和归纳，不连续三页重复相同卡片堆叠；不为了变化破坏必要的对照一致性。
- 正常整套汇报保持同一配色和填充风格；六色展示包是挑选模板用的，不是要求正式汇报逐页换色。
- 交付必须检查缩略图整套节奏，以及每页原图、图注、标注与字号。静态审计通过不等于视觉检查完成。
