# 案例示范 1：黑麂种群密度评估的方法学争议与共识收敛

> **案例说明**：本案例展示了如何运用 `literature-synthesis` 技能，对黑麂（*Muntiacus crinifrons*）在古田山/钱江源国家公园种群密度的长期学术分歧进行争议诊断、证据对决、方法论溯源与共识界定。

---

## 1. 任务背景与核心科学争议

黑麂是国家一级重点保护野生动物。关于钱江源/古田山地区黑麂的核心种群密度，不同时期、采用不同技术方案的研究给出了截然不同的数值结论：
- **历史样线痕迹派**：报告种群密度高达 $3.5 \sim 4.8\text{ 只/km²}$。
- **非损伤性粪便标记重捕派 (Capwire)**：报告密度为 $1.8 \sim 2.5\text{ 只/km²}$。
- **空间显式捕获重捕派 (SECR / 红外相机网格)**：报告密度为 $0.8 \sim 1.4\text{ 只/km²}$。

学界面临的争议焦点：**该区域黑麂真实密度到底处于哪个数量级？早期高密度是否反映了种群历史衰退，抑或是方法学系统性假象？**

---

## 2. 争议分类与方法论根因剖析

经 `controversy_analyzer.py` 诊断，该分歧归属于 **Type B（方法论人工产物）** 与 **Type D（尺度与边界依赖）** 的复合争议：

### 2.1 冲突根因 1：有效抽样面积（Effective Sampling Area）与边界效应
- **Capwire / 传统截线法**：必须人为假定一个外围缓冲区宽度（Buffer strip width, 如假设动物活动半径为 500m）。若缓冲宽度设置过保守，计算分母（有效面积）严重低估，导致密度数值被动膨胀。
- **SECR 范式**：通过探测函数 $g(d) = g_0 \exp(-d^2 / 2\sigma^2)$，显式将个体活动中心与距离衰减参数 $\sigma$ 进行状态空间联合估计，彻底消除了人为假定抽样边界的系统性偏差。

### 2.2 冲突根因 2：探测率不完全（Detection Incompleteness）与异质性
- **样线痕迹法**：严重依赖冬季积雪中蹄印与粪堆保存率，假设排便率为恒定常数（每日 15-20 堆）。未校正降雨冲刷、微生物分解及巡护人员视线遮挡率。
- **红外相机 SECR**：直接估计基线探测率 $g_0$，校正微生境遮挡、坡度与相机会话有效工作日。

### 2.3 冲突根因 3：非损伤性取样中的“幽灵个体（Shadow Individuals）”
- 早期微卫星粪便取样若未严格执行多管 PCR（Multi-tube protocol），等位基因脱落（ADO）可达 15%~25%，导致同一头黑麂的不同粪便被误判为不同个体，显著虚增个体数 $N$。

## 4. 共识提炼与适用边界界定 (Consensus Synthesis)

### 4.1 收敛共识（Consensus Level 3: 条件限定与范式收敛）
> **综合学术共识**：
> 早期文献报告的 $>3.0\text{ 只/km²}$ 极高密度主要是由样线痕迹外推与有效抽样面积低估导致的**方法论虚高**，而非反映黑麂历史种群发生了灾难性崩塌。
> 在**常绿阔叶林成熟林核心区**，黑麂的实际真实种群密度稳固落在 **$0.9 \sim 1.4\text{ 只/km²}$** 区间；而在人工杉木林或边缘干扰带，密度急剧下降至 $<0.3\text{ 只/km²}$。

### 4.2 适用边界条件
1. **生境约束**：仅适用于浙西皖南中高海拔（海拔 600-1100m）原始及恢复良好的常绿阔叶林与针阔混交林。
2. **方法约束**：密度估算必须采用空间显式模型（SECR）或经过多管严格质控（$\ge 3$ 次重复，PID-sibs $< 0.001$）且校正边界缓冲区的基因标记重捕。

### 4.3 红队质询 (Devil's Advocate Challenge)
> 🚩 **红队审计**：SECR 的 $1.12\text{ 只/km²}$ 是否存在系统性“低估”？
> 黑麂生性极度胆小警觉，且偏好在悬崖裸岩和极密杜鹃灌丛穿行。红外相机大多架设于兽径（Animal trails），可能对繁殖期隐蔽育幼的雌性造成偏好性漏拍（Sex-biased detection heterogeneity），导致基线探测率 $g_0$ 被高估，进而压低密度估计值。
