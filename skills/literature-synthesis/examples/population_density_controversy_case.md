# 案例示范 1：濒危兽类种群密度评估的方法学争议与共识收敛

> **案例说明**：本案例展示了如何运用 `literature-synthesis` 技能，对雪豹（*Panthera uncia*）在三江源/祁连山地区种群密度的长期学术分歧进行争议诊断、证据对决、方法论溯源与共识界定。

---

## 1. 任务背景与核心科学争议

雪豹是高原生态系统的顶级旗舰物种。关于特定核心栖息地雪豹的种群密度，不同时期、采用不同技术方案的研究给出了截然不同的数值结论：
- **历史痕迹样线派**：报告局部种群密度高达 $3.0 \sim 4.5\text{ 只/100 km²}$。
- **非损伤性粪便标记重捕派 (Capwire)**：报告密度为 $1.8 \sim 2.6\text{ 只/100 km²}$。
- **空间显式捕获重捕派 (SECR / 红外相机网格)**：报告密度为 $0.8 \sim 1.5\text{ 只/100 km²}$。

学界面临的争议焦点：**该区域雪豹真实密度到底处于哪个数量级？早期高密度是否反映了种群历史衰退，抑或是方法学系统性假象？**

---

## 2. 争议分类与方法论根因剖析

经 `controversy_analyzer.py` 诊断，该分歧归属于 **Type B（方法论人工产物）** 与 **Type D（尺度与边界依赖）** 的复合争议：

### 2.1 冲突根因 1：有效抽样面积（Effective Sampling Area）与边界效应
- **Capwire / 传统截线法**：必须人为假定一个外围缓冲区宽度（Buffer strip width, 如假设动物活动半径为 5 km）。若缓冲宽度设置过保守，计算分母（有效面积）严重低估，导致密度数值被动膨胀。
- **SECR 范式**：通过探测函数 $g(d) = g_0 \exp(-d^2 / 2\sigma^2)$，显式将个体活动中心与距离衰减参数 $\sigma$ 进行状态空间联合估计，彻底消除了人为假定抽样边界的系统性偏差。

### 2.2 冲突根因 2：探测率不完全（Detection Incompleteness）与异质性
- **样线痕迹法**：严重依赖积雪中足迹与刨坑刮痕保存率，假设排便与标记行为为恒定常数。未校正大风侵蚀、降水掩埋及巡护人员视线遮挡率。
- **红外相机 SECR**：直接估计基线探测率 $g_0$，校正地形遮挡、坡度与相机会话有效工作日。

### 2.3 冲突根因 3：非损伤性取样中的“幽灵个体（Shadow Individuals）”
- 早期微卫星粪便取样若未严格执行多管 PCR（Multi-tube protocol），等位基因脱落（ADO）可达 15%~25%，导致同一只个体的不同粪便被误判为不同个体，显著虚增个体数 $N$。

## 4. 共识提炼与适用边界界定 (Consensus Synthesis)

### 4.1 收敛共识（Consensus Level 3: 条件限定与范式收敛）
> **综合学术共识**：
> 早期文献报告的高密度估计主要是由样线痕迹外推与有效抽样面积低估导致的**方法论虚高**，而非反映历史种群发生了灾难性崩塌。
> 在**高原峡谷优质猎物分布核心区**，雪豹的实际真实种群密度稳固落在 **$0.9 \sim 1.5\text{ 只/100 km²}$** 区间；而在开阔荒漠化草甸或边缘干扰带，密度急剧下降至 $<0.3\text{ 只/100 km²}$。

### 4.2 适用边界条件
1. **生境约束**：仅适用于青藏高原及天山山系高海拔（海拔 3500-5000m）岩羊等有蹄类猎物丰富的高山裸岩与高山草甸生境。
2. **方法约束**：密度估算必须采用空间显式模型（SECR）或经过多管严格质控（$\ge 3$ 次重复，PID-sibs $< 0.001$）且校正边界缓冲区的基因标记重捕。

### 4.3 红队质询 (Devil's Advocate Challenge)
> 🚩 **红队审计**：SECR 的估算值是否存在系统性“低估”？
> 雪豹偏好在高海拔山脊线与陡峭悬崖活动。红外相机若多架设于相对平缓的山脊垭口，可能对偏好悬崖深谷育幼的雌性造成偏好性漏拍（Sex-biased detection heterogeneity），导致基线探测率 $g_0$ 被高估，进而压低密度估计值。
