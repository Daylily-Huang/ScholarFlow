## 2. 详细维度说明与选项设计

### S1: 综合目的与产出定位 (`CRITICAL`)
- **[A] (Recommended)** 全景学术争议诊断与学派演进图谱 — *[依据：揭示前沿争鸣与深层理论范式分歧的标准产出]* `[高置信度]`
- **[B]** 共识度分级与边界标定 — *[依据：侧重梳理公认结论与不确定性适用]* `[中置信度]`
- **[C]** 争议驱动型叙事综述 (Narrative Review) — *[依据：生成可直接嵌入学位论文开题/引言的综述文本]* `[高置信度]`

### S2: 核心争鸣命题与待检验假设 (`CRITICAL`)
- **[A] (Recommended)** 因果效应方向分歧（促进 vs 抑制） — *[依据：最典型且最具启发性的核心学术冲突]* `[高置信度]`
- **[B]** 数值量级与阈值分歧（效应量差异巨大但方向一致） — *[依据：定量模型调优与参数边界辨析]* `[中置信度]`
- **[C]** 机制模型与解释范式竞争（底层逻辑模型竞争） — *[依据：理论机制对立分析]* `[中置信度]`

### S3: 证据库来源与纳入边界 (`CRITICAL`)
- **[A] (Recommended)** 经过 Extraction 严格质控与审计的结构化证据表 (E1-E4 完备) — *[依据：保证跨篇比较建立在经过审计的事实基石上]* `[高置信度]`
- **[B]** 包含未经细粒度提取的文献全文集合（边提边合） — *[依据：快速粗览模式]* `[需权衡]`

### S4: 比较单元与聚合粒度 (`CRITICAL`)
- **[A] (Recommended)** 以独立实验 / 独立研究点为单元对比 — *[依据：消除篇内异质性，避免组间混杂]* `[高置信度]`
- **[B]** 以单篇文献总体结论为单元对比 — *[依据：宏观计量梳理]* `[中置信度]`

### S5: 可比性边界与条件控制 (`HIGH_IMPACT`)
- **[A] (Recommended)** 按核心混杂变量（系统、时间点、剂量梯度）分层后再对比 — *[依据：防止出现辛普森悖论与假争议]* `[高置信度]`
- **[B]** 跨条件直接合并总体对比 — *[依据：仅在实验高度均一标准化时适用]* `[需权衡]`

### S6: 证据质量评级与加权策略 (`HIGH_IMPACT`)
- **[A] (Recommended)** 多维循证质量加权（根据样本量、研究设计、偏倚风险赋予权重） — *[依据：循证综合 Gold Standard，杜绝劣质文献绑架结论]* `[高置信度]`
- **[B]** 等权重民主计数（一文一票） — *[依据：简单频次统计，存在质量稀释风险]* `[需权衡]`

### S7: 学派识别与聚类灵敏度 (`HIGH_IMPACT`)
- **[A] (Recommended)** 依据核心机制假设与方法学传统进行聚类（9类学术争议分类法） — *[依据：深入揭示学科分歧的深层理论根源]* `[高置信度]`
- **[B]** 依据作者合著网络与引用社区聚类 — *[依据：文献计量学视角]* `[中置信度]`

### S8: 时间演进与范式转移切片 (`DEFAULTABLE`)
- **[A] (Recommended)** 按时间窗口划分阶段，标注关键里程碑文献与演变拐点 — *[依据：展现学科知识进化轨迹]* `[高置信度]`
- **[B]** 静态截面分析（忽略时间先后顺序） — *[依据：纯横截面状态陈述]* `[中置信度]`

### S9: 反方辩驳与异见证据策略 (`DEFAULTABLE`)
- **[A] (Recommended)** 强制启动独立反方挑刺（Devil's Advocate 审计），挖掘潜在反例与局限 — *[依据：ScholarFlow 独创防证实偏差机制]* `[高置信度]`

### S10: 知识空白与上游反馈机制 (`DEFAULTABLE`)
- **[A] (Recommended)** 生成标准 Upstream Gap Request 结构化任务包反馈上游 — *[依据：形成研发生态闭环]* `[高置信度]`

### S11: 叙事综述产出深度 (`DEFAULTABLE`)
- **[A] (Recommended)** 学术论文级别深度，段落围绕 Claims 组织并标注证据等级与争议点 — *[依据：可直接用于高水平学术写作与发表]* `[高置信度]`

## 3. 提问生成与默认规则

1. 启动时解析已有任务指示，将已确定项标记为 `[INFERRED]`；
2. 动态挑选未决的 `CRITICAL` 维度（S1-S4）与关键 `HIGH_IMPACT` 维度（S5-S7），组合为 **3~5 题**；
3. 其余 `DEFAULTABLE` 维度（S8-S11）自动应用默认选项 A，并在 Protocol Snapshot 中打上 `[DEFAULTED]` 标签；
4. 提问输出后，**Agent 必须执行 STOP Rule**，等待用户回复。
