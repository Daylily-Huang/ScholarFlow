# 领域配置文件：宏观与种群生态学 (Ecology Domain Profile)

> **适用范围**：宏观生态学、野生动物种群生态学、栖息地评估、景观生态学与保护生物学研究。

---

## 1. 核心研究主题与典型方法学矩阵

| 研究主题 | 传统方法范式 (Traditional) | 现代前沿范式 (Modern/Contemporary) | 核心方法差异与演进驱动 |
|---|---|---|---|
| **种群密度与丰度估计** | 痕迹样线法 (Transect surveys)<br>距离取样法 (Distance sampling)<br>非显式标记重捕 (Lincoln-Petersen) | 空间显式标记重捕 (SECR / SCR)<br>随机相遇模型 (REM / REST)<br>非配对红外相机占用模型 (Royle-Nichols) | 从“假设空间均质/无边界探测”转向“显式建模空间探测衰减与个体活动中心” |
| **栖息地选择与适宜性** | 出现点频数统计 (Chi-square/Bonferroni)<br>生境利用率与可利用率对比 | 最大熵模型 (MaxEnt)<br>资源选择函数 (RSF / iSSA 步长选择)<br>动态占域模型 (Dynamic Occupancy) | 从“静态生境关联”转向“时空动态可利用性、步长移动阻力与不完全探测率联合建模” |
| **景观破碎化与连通性** | 最小成本路径 (Least-Cost Path)<br>斑块-廊道-基质几何分析 | 电路理论 (Circuitscape)<br>空间形态学 (MSPA)<br>个体移动阻力表面与连通网络拓扑 | 从“单一最优廊道”转向“多重流动路径、电流冗余度与生态阻力多方案对比” |
| **物种共存与种间竞争** | 时间位相重叠度 (Pianka index / Overlap)<br>相关系数分析 | 空间-时间双变量联合占域 (Two-species Occupancy)<br>贝叶斯多物种状态空间模型 | 剥离生境偏好共享伪相关，校正相互探测干扰，量化真实种间排斥/吸引 |

## 2. 领域高发学术争议类型与诊断策略

### 2.1 争议 1：绝对种群密度数值的巨大离散 (Type A / Type B)
- **现象**：同一物种在同一地理区域，不同研究报告的密度差异可达 2~10 倍。
- **根因诊断清单**：
  1. **有效抽样面积边界效应 (Edge Effect)**：传统非显式方法（如截线法或 Capwire）人为假设缓冲区宽度（Buffer width），严重低估抽样有效面积，导致密度计算值偏大；SECR 通过参数 $\sigma$ 显式计算个体探测距离衰减，有效纠正边界膨胀。
  2. **探测概率假定 ($p$)**：传统方法假设“视线内探测率=1”或“相机捕获率=常数”；现代模型校正了植被遮挡、微地形与天气对探测率 $g_0$ 的动态干扰。
  3. **调查季节与活动节律**：冬季聚集期（如采食越冬地） vs 春夏季扩散期；发情期高移动率导致相机触发率虚高。

### 2.2 争议 2：生境适宜性预测范围与实际分布脱节 (Type D / Type E)
- **现象**：MaxEnt 模型预测该区域高度适宜，但实地红外相机调查长期未记录。
- **根因诊断清单**：
  1. **采样偏差与空间自相关 (Sampling Bias)**：存在点集中在巡护道路或高可达性区域，未作空间去相关过滤（Spatial filtering/thinned），导致模型过度拟合人为干预带。
  2. **背景点 (Background Points) 选取范围不当**：选取范围过大（超出物种历史扩散极限）导致 AUC 虚高；选取过小导致环境变量梯度截断。
  3. **历史人为压力与局部灭绝**：适宜生境存在，但因偷猎、隔离等非环境因子导致物种已局部绝迹（Sink habitat / Extinction debt）。

### 2.3 争议 3：线形工程（道路/铁路）对动物迁徙的阻隔影响 (Type A / Type G)
- **现象**：部分学者认为公路未造成基因或种群隔离；另一部分学者报告严重阻隔。
- **根因诊断清单**：
  1. **结构连通性 vs 功能连通性**：廊道桥梁在物理结构上存在，但由于车流量、路灯噪声或人类活动，动物在行为上拒绝穿越。
  2. **滞后效应 (Time-lag Effect)**：道路建成数十年后，种群间才显现等位基因漂移分化；早期微卫星调查难以捕获近期隔离信号。

## 3. 关键评价指标与置信度门槛

在综合分析宏观与种群生态学文献时，必须提取并审计以下硬性指标：

1. **抽样努力量 (Sampling Effort)**：
   - 红外相机：有效工作日总数 (Camera trap-days)、相机位点数 (Stations)、网格密度 (km² per station)。建议：单个位点工作天数需 $\ge 30$ 天，全区有效相机日 $\ge 1500$ 天以支撑占域模型。
   - 样线法：样线总长度 (km)、重复调查次数、单公里遇风/痕迹发现率。
2. **模型拟合与选择指标**：
   - 占域/SECR 模型：Akaike 信息准则 ($\Delta \text{AIC} < 2$ 表明等价支持)、重抽样检验 (Bootstrap goodness-of-fit)。
   - 适宜性模型：TSS (True Skill Statistic, 优于易受普遍率影响的 AUC)、Boyce 指数 (连续空间评估)。
3. **参数不确定性区间**：
   - 任何密度或丰度估计值，若**未报告 95% 置信区间 (95% CI) 或标准误 (SE)**，证据等级降至 E3，不可作为共识基准。

## 4. 典型反模式（Anti-Patterns）在生态学综述中的识别

- **反模式 1：小样区密度盲目全区外推**
  - 在面积仅 5 km² 的高密度核心区实测 $D = 3.5\text{ 只/km²}$，直接乘以此物种总栖息地 500 km² 得出“全区有 1750 只”。必须标定空间异质性边界，拒绝线性外推。
- **反模式 2：忽视休眠与活动节律造成的假未检出 (False Absences)**
  - 将无记录直接判定为“物种不利用该生境”，未建立探测概率 $p$ 估计。
