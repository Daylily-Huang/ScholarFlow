# 通用来源整理、术语与引注

适用于所有学科。问题不是某个物种或某篇PDF，而是提取文本失去结构后仍直接翻译。先恢复可核对的来源，再撰写译文；不能靠译文流畅证明原文完整。

## 1. 提取块不等于自然段

- 优先采用可靠出版商JATS/HTML段落结构，并与当前版本核对；PDF按实际栏序、段首缩进、跨栏/跨页接续与图表位置判断。空行和文本框只能作为线索，不能据此宣称自然段已恢复。页眉、脚注、图注、正文、书目分别处理。
- 分开处理三种问题：单词因行末排版而断开；一个自然段被跨页/插图拆散；多个自然段被提取器合并。不能只做英文拼写修复而忽略论证边界，也不能把相邻小写开头一律拼接。
- 保留不可覆盖的提取原件。小范围且唯一匹配的字形问题沿用source.corrections；段落合并/拆分、顺序调整或需要同时恢复行内样式时，另存规范化转录，记录原文件/页码/原片段→新片段及理由，重新解析。校验器的--source须指向该规范化转录，原提取件也保留。不能改SHA绕过校验。
- 重解析会改变内容指纹ID；保留旧ID→新ID的一对多/多对一映射，更新译文、证据、图注与动图引用。已有批注不静默迁移；文字或上下文不唯一时待重定位。
- 不全局删除连字符、空格或连接数字：复合词、负号、范围、基因名、软件版本、年代和文献号可能形似。只能根据原页或同版本结构化来源逐项决定。

## 2. 术语先辨认所指，再定中文

先建立本篇guide.terminology，重点覆盖影响研究对象、方法和结论的术语及多义词，不建无用大词典。每项保存id、forms（英文形式）、identity（此处具体所指/定义）、preferred_zh、aliases（允许的别名，可空）、evidence（核实来源和定位）及refs（本篇段落）。首次必要时并列英文/规范中文/别名，随后统一。

物种用学名确认身份；医学、化学、统计等优先适用的命名规范/专业来源；人文社科和历史文学核对学派、作者定义、时代含义及已有译本。没有稳定中文名时给出工作译名并保留英文，不能把通行别名判错，也不能把同一英文不同含义强行统一。来源只核对到名称时，不写成全文理论已核验。

逐段terms用于已核定术语对；同形异义时加term_id绑定本义项。机器会检查这些显式术语对是否符合术语表；不会判断中文解释是否正确，也不会完整扫描散文中的指代、词形变化或所有名称。人工沿译文、三/十分钟、白话、图注、词汇和动画文案核对核心术语及其所指，尤其是简称是否产生歧义。vocabulary仍使用该段语境释义，不能把每个普通多义词都锁成唯一译名。

## 3. 保留引注的身份、位置与关联

引用标记不是正文数值。区分文献号、脚注/尾注号、公式编号、数学上下标、单位、年代和软件版本。顺序、范围、逗号分隔、原注内容及书目目标按来源保留；不能“看见单词后有数字就升为上标”，也不能删除数字来美化。

JATS的xref/sup及书目目标优先沿用；PDF需看原页字形与参考文献表确认。英文通过source.inline_runs恢复安全的sup/sub及target；连接后的文本须严格等于raw.strip()，目标必须存在。若原有字形修订与inline_runs冲突，先形成可追溯的规范化转录并重解析，不能同时绕过校验。多目标引注可分成多个run，分隔符仍保留；普通target是来源交叉引用，不自动证明它属于文献号。

译文保留同一引注及其支撑范围，可用纯文本[12]或[12–14]，不能因中英调序把出处挂到另一个说法。当前译文不自动继承英文上标/跳转，禁止宣称两侧已自动同步。作者—年份制、注释制、档案编号同样检查，不只验数字型。没有可验证目标时保留标记并记录未解析，不猜配书目，不把未知角标当指数或正文。

## 4. 程序疑点与真实审读分开

先运行：

```powershell
python scripts/audit_source.py <fulltext.json>
```

输出source_risks：word-number（字母后粘数字）、broken-word（疑似排版断词）、paragraph-boundary（疑似续段）。只发现一部分英文排版风险；合法基因名/复合词也可能出现，绝不自动改字。无风险不代表结构、术语或引用已通过。图/元信息隔开的续段、缺失内容和中文/其他语言问题仍须来源清点。已带上标且有链接的数字不再报粘连，但其含义/目标仍需人核对。

新完整稿加--require-source-review。fulltext.source_review分开记录structure、terminology、citations，各项{status: checked/not_applicable/pending, evidence: [实际文件/页码/段落或来源入口], note: 具体检查范围与结果}。无术语/无引注可not_applicable，但需说明依据。pending不能通过严格构建；source.status=verified只沿旧定义表示原页文字核对，不可据此批量补齐三项审读。

每个当前自动疑点在decisions中记录{risk_id, resolution, evidence:[定位]}：可说明已按原页修订、属于真实名称或无需连接。修订后重跑，风险ID随原文/位置变化，去掉过期decision；raw不变但显示修订时仍记录对应疑点。另把人工发现、启发式未发现的问题放issues：{id, aspect, refs, description, evidence, status:open/resolved, resolution}；resolved需具体处理，open阻断严格构建。

```json
{
  "source_review": {
    "structure": {"status":"checked","evidence":["source-review.md#structure"],"note":"填写真实栏序、自然段及跨页核对范围"},
    "terminology": {"status":"checked","evidence":["source-review.md#terminology"],"note":"填写核心概念与译名核实范围"},
    "citations": {"status":"checked","evidence":["source-review.md#citations"],"note":"填写引注、原注与书目关联核对范围"},
    "decisions": [],
    "issues": []
  }
}
```

以上只是字段说明，不能复制示例注释宣称完成。程序检查记录是否存在、引用ID、显式译名冲突、未审疑点和未决问题；不能验证evidence所述工作实际发生，不能用填满checked代替审读。证据文件随reading-data保存；真正未完成时交待补稿并说明范围。

## 5. 内容与浏览器验收

沿已整理的自然段对照原页检查完整句与段落落点；对跨栏/跨页、行末断词、嵌套引文及注号密集位置逐处查，而非只看首段。核心术语逐项核对所指、译名、别名和首次解释。引注按本篇清单检查有无漏号/错挂/未解析目标；实际点击有链接的标记，并检查正文数值/公式未误处理。三条路线、段落词汇、原图和公式保留；生成页问题回输入/渲染器重建，不补丁改HTML。报告分开写自动检查、来源结构核对和翻译语义审读范围，不能笼统宣称全文已核验。
