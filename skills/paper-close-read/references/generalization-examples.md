# 跨文献写作：先把事情讲通，再安排字段

## 每篇的实际工作顺序

读完正文及关键图表后，在阅读资料写一份简短论证骨架：研究场景和问题、旧方法卡点、作者的关键选择、得到的证据、结论；每次转折说明为什么需要下一步并附来源块。不是所有文章都有旧方法失败或因果机制，按本篇实际论证写。标出哪些是观察、实验结果、作者解释和教学补充。由此决定重难点及动图插入位置，再写3分钟和10分钟路线。

3分钟用背景—缺口—问题—方法/读法—发现—结论六步总览讲清整篇工作；10分钟展开其中省略的必要推理。入门不是把正文故事情节压缩一遍，要明确研究者用了什么材料、怎样论证、得出了什么。章节末的 connection 要接具体未解问题；末节回到开头问题，不写“接下来看看结果”等空过渡。删掉段落后若推理没有损失，检查它是否只在重复目录。

逐段先问：读者究竟卡在哪个词、哪项操作、哪个隐含推理？note 用实际对象讲操作及后果，必要时用一个贴近研究的小例子；keys 则提取本段的论证骨架。两者作用不同，不能互相换词复制。条数随真实推理，不用两条/三条配额。比较段可先分支再汇合，综述的多项研究不能硬串成因果。

## 跨学科示例（完全虚构，仅示范写法）

假设一篇材料研究的段落是：两种涂层起初都防水；反复弯折后，甲出现裂缝并渗水，乙仍完整。作者认为柔韧性可能帮助乙维持防水性。

弱白话：“说明要重视涂层柔韧性，比较结果有差异。”
弱要点：“比较两种涂层。提出可能机制。”——换成任何材料几乎都适用，没有解释结果怎样支持判断。

白话：刚涂好时，两种涂层都像一件不漏水的雨衣。真正拉开差距的是反复弯折：甲被折出了缝，水有了穿过去的路；乙还能跟着材料一起弯，表面保持完整。因此，作者怀疑乙的优势在于用过以后仍能保住这层屏障。这里同时观察到了裂缝和渗水；要确认裂缝就是原因，还可以进一步单独改变裂缝情况做比较。

逻辑要点：
- 起初两者都防水，说明初始防水能力本身不能解释后来的差距。
- 弯折后，甲的开裂伴随渗水，乙保持完整也保持防水，差异由此指向使用过程中的结构变化。
- 因而作者提出“柔韧性帮助维持屏障”的解释；本段的证据支持这条解释线索，尚未把它单独检验出来。

这段需要三步，因为原段确有三层推理。若下一段只交代“随后每隔一小时称重”，一句白话说明用重量跟踪水分变化，一条逻辑交代它如何测量后续变化即可。不得为统一版式补出不存在的论证。

本例的导读主线可以是：新涂层刚做出来都防水，怎样分出耐用性？→用反复弯折模拟使用→把弯折前后、两种材料交叉比较→从裂缝与渗水的对应提出机制解释→回到选材需要关注长期完整性。10分钟中在“裂缝怎样影响屏障”的解释下放机制示意，画面要演示裂缝形成与水的通路；不能借用血管动画换标题。示意不能冒充实验观察。

## 成稿后的内容审读

另看三个不同卡点，理解“推演一次”如何迁移，而不是只改比喻中的名词：

- **遗传学的显性**：先拿一个 Aa 个体，说明 A 让性状被表现出来；再让它与另一只 Aa 配对，孩子可能得到 AA、Aa 或 aa。看到的是性状怎样表现，尚不能由此推出 A 会越来越常见。读者于是能分开“表现出来”和“遗传材料所占份额”，再回到整个人群的配对计算。这里不把教学配对当作 Hardy 原文整个人群的比例结果。
- **逻辑中的接受与推出**：笔记上先写 A、B，乌龟都承认。阿喀琉斯说“那你就该承认 Z”，乌龟却要求把这条要求也写成 C。纸上增加了 C，但还没有发生从这些句子走到 Z 的动作；继续把要求写成句子，只会得到更长的清单。这样读者能指认“多一条前提”和“使用规则走一步”的差别；对原作的解释仍要与引文逐段对应。
- **文学中的旁听**：先问这个场景里谁在说、谁原本是听众、谁实际上听见，再跟着具体措辞看人物获得了什么新信息。让读者看见“信息到了谁那里”，再谈视角和声音的解释；不要先扔出“主体性建构”再用“话语赋权”解释它，也不把一种解读说成作品唯一的意思。

这三例依次演示配对、清单增加、信息通道，动作不同；不能将同一个“流水线”比喻强套给三种材料。具体论文需另选真实段落、保留原文定位并核对措辞。

先逐节检查导读桥接，再抽看一个概念段、方法段、结果段、讨论段及简短承接段；某类不存在就跳过。遇到模板化写法，检查同节其余段落并改到讲通为止。

- 口头复述：不看字段名，能否讲出作者为何这样做、证据怎样到达结论？
- 替换对象：换掉研究对象后几乎原封不动仍适用的白话，通常过于泛化，补回本段具体操作或关系。
- 调换次序：有前后推导的要点能任意换序而不损失意义，检查是否只是平行摘要；本来就是比较分支的段落不用假造先后。
- 新手视角：解释中出现一个术语，就问读者是否已知道它指哪个对象、如何操作或观察。必要定义随用随讲。
- 证据对照：比喻、补充知识和通俗因果词有没有超出原文？只修正实际越界，不给每段添加防御性套话。

保存简短审读记录：检查了哪些来源块、具体问题、怎样改。不要把字段齐全、要点数量多样或自动测试通过当成文笔合格；不因此要求用户额外审批。
