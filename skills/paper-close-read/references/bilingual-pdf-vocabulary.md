# 双语 PDF 与逐段语境词汇

## 词汇在写作阶段完成

读清段落后，为实质性英文段落填写 `translations[].vocabulary`，例如 `[{"en":"random mating","zh":"随机交配"}]`。英文使用该段**实际出现的词形或连续词组**；释义解释它在此处的意思。词可以是学科术语、常见学术表达、连接推理的短语或读者容易误解的普通词，不要一律挑最长的词。

按段落难度和读者基础选择，通常少量即可，**不规定每段同样条数**。短句只有一个有用表达时就写一个；没有值得记忆的词时允许空数组，不用 the、and 等凑数。中文原文不强造英文词汇。元信息、书目不强制加词。`terms` 是兼容保留的术语字段，不替代本段词汇。

逐条核对原句和中文：fertile 在遗传学讨论中是“有繁殖能力”，grant 在逻辑对话中可能是“承认命题”；statistically significant 与日常“重要”不同。词形与原段一致，缩写首次说明；不要凭空生成读音、词源或高频标签。技术校验仅检查词组实际出现、重复与字段形状，不会证明释义正确。内容审读须看上下文。

HTML 在对应段落下方显示“本段重点词汇 / Words in context”；PDF 同段保留。词汇不替代白话或递进逻辑，不增加页面折叠层级。修改数据后重建，不能补写成品 HTML。

## 浏览器导出

点击工具栏“导出双语 PDF”，选择 A4 横向（推荐）或纵向，可选择包含白话与逻辑、作者信息和参考文献等附录，然后点击“排版并打开打印”，在系统打印窗口选择“另存为 PDF”。默认导出全文原文和译文，**不受当前阅读路线或检索过滤影响**。导出后仍可继续使用原页，批注和阅读进度沿用原记录。

这是静态的原文—译文对照文档：保留公式、原图表和语境词汇；交互动图、批注与阅读工具仍在 HTML 中。长段可跨页，栏头重复；不声称每一行逐句对齐。不能将浏览器打印按钮本身当作已经交付 PDF，用户要 PDF 时必须实际生成并检查文件。

## 命令行直接生成文件

只需 Python 标准库和本地 Chrome、Chromium 或 Edge，不需要另装 Playwright、PDF 库或上传服务：

```text
python scripts/export_pdf.py reader.html 双语对照.pdf --work-dir <任务临时目录>
```

可选 `--paper portrait`、`--no-explanations`、`--include-aux`；自动发现失败时用 `--browser <浏览器可执行文件>`。脚本在任务临时目录使用独立浏览器 profile，先核验排版已完成，再生成 PDF；失败不替换已有输出。不包含 OCR、自动英译或跨语言翻译服务；英文原文及中文译文仍须在阅读资料中准备并核对。中文来源只导出既有原文与对照文本，不能冒称已有英文译文。

## 验收

1. 用真实自然科学与人文篇从输入重建，选择含公式、长段和图表的页面，不仅测试合成段落。
2. 实际导出 PDF，检查可选择/搜索的中英文文字、栏头、段落定位、词汇、公式和来源归属。
3. 渲染并目视看首页、跨页和末页，检查丢字、溢出、异常空白和文字叠加。检查长表、长公式时按实际问题改排版器或输入，再完整重建。
4. 在浏览器验证打印选项、取消、恢复阅读、检索过滤后导出全文；确认正文默认展开、动图和旧批注功能仍可用。不要通过修改 PDF 或最终 HTML 来掩盖通用排版缺陷。
