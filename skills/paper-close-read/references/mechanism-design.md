# 从论文主线规划机制演示

先读清全文与关键原图，写出研究问题、如何回答、关键证据、结论。沿这条主线找理解障碍，再为值得动态展示的部分安排场景。规划不是按页数分配动图，也不要求每节都有。

每项规划回答：读者为什么卡住？用哪些看得见的对象表示？什么随步骤变化？每一步说明什么？放在哪个原文块旁？哪些图形/数值仅为教学设定？对应哪些原文证据？保存在本篇阅读资料中。

优先展示空间关系与状态变化、累计与非线性转换、隐变量与观测、物质流动与作用链。实验数据图保留原数据；机制图可以简化形状，区分个体/群体、细胞/器官、假说/实验结果。画箭头前先确认原文支持的是先后关系、干预线索还是因果链。

## 输入

`guide.json`可增加`mechanisms`数组，每项：

```json
{"id":"motion-example","scene":"hazard","title":"沿路线累积，再换成概率","question":"为什么不能直接把概率相加？","anchor":"对应段落ID","refs":["依据块ID"],"stages":["局部强度从哪里来","沿线累计为H","由H转为p"],"note":"几何和参数用于演示"}
```

当前场景是有具体科学含义的实现，不是万能动画：

| scene | 实际演示 |
|---|---|
| spatial | 固定中心、三轮位置、路线与遭遇表；演示位置并非真实连续轨迹 |
| hazard | 固定动物位置，搜索沿路推进、局部强度累加，再转成p=1−exp(−H) |
| augmentation | 3行观测＋5行候选，成员开关示意，N=Σw；示意数不是论文估计 |
| boundary | 同一中心附近的位置进出记录边界；S与样地分开 |
| vessel | 钙流入变化与平滑肌张力、血管管腔变化；用于离体血管机制 |
| cholesterol | 正常外排与ABCA1受抑的细胞对比，胆固醇逐渐积聚 |
| oxidative | 人源细胞实验中的氧化应激、自噬/膜变化与细胞损伤线索；讲解注明跨实验综合 |

由`render_mechanisms.py`生成结构、`mechanisms.js`画Canvas并管理播放，单文件内嵌，不用外部视频或字体。Canvas提供文本替代和逐步文字说明；手机在图内部横向查看，按钮和讲解正常换行。guide.animations帧播放器仅用于显式legacy兼容稿；新叙事页使用mechanisms与walkthrough.motions。

## 验收

补充场景：`gene_pool`用于随机交配时基因型重新组合，`visual.initial`是三个有限非负AA/Aa/aa权重（总和大于0），图中按配子频率计算下一代期望；教学起点与论文数据要分清。`inference_regress`专门对照不断添加条件命题与实际执行推断的动作，适用于Carroll式回退论证，不当万能哲学模板。它的右侧是教学区分，不代表作者已经给出最终解法。

看首帧、中间帧和末帧，确认图形真的解释了变化；核对分步文字与画面同步、符号对应原文、没有把猜想画成实测结果。实际操作播放/暂停/拖动/分步/速度，检查离开视区和切路线暂停。只证明按钮可点不等于演示有教学价值。

10分钟导读的 motions 字段指向既有场景配置，但渲染为章节内播放器，而非跳转链接。实例ID采用 guide-motion-章节号-原场景ID，防止同页多处演示重名；场景来源、分步说明与正文一致，播放状态分别管理。验收须在导读内操作所有实例，确认没有切换至逐段精读，切路线后隐藏实例暂停。


## 新学科的场景扩展

现有场景不匹配时，先按本篇概念设计对象和状态变化，再扩展 scripts/render_mechanisms.py 的 SCENES 与 assets/mechanisms.js 对应绘制/场景分支，补场景输入和实际浏览器检查。仅登记场景名而不实现画面不算支持。导读通过 walkthrough.motions 引用，同一配置在全文和导读有独立实例；动作、阶段文字、来源必须一致。简单静态关系不用为了动画数量强行动起来。

新场景：molecular_sampling 演示A/B分子从提取液进入反应管再对应读带；pcr_slippage 演示早期短重复支系及后代累积；replicate_consensus 演示独立阳性记录逐次加入与不同含混模式。三者用固定教学示例，不是项目判型算法，不套用到无关概念。第一场景分子离开原液后不再同时留在原位置，避免把分装误画成复制。

跨学科可用argument_map（支持/反驳等显式关系）、evidence_coding（三阶段材料解释）、repeated_measures（区间记录与时点）。visual字段见content-contract.md；全新机制仍需设计真正合适的场景，不能把所有历史、文本与理论都硬套为线性因果。


历史/文学实测场景补充：source_timeline逐层显现事件、记录、研究解释，移动点仅表示取材核对顺序；communication实际移动信息点并切换说话、旁听、书信通道；text_focus保留短引句，通过精确子串高亮展现措辞变化。两处实例都放在对应解释下，先/中/末帧与文字同步。手机宽图显示横向滑动提示。

不要用暴力行为重演代替史料解释；法律归责问题应画规则、证据与解释关系。文学不是给人物填能力值：演示应呈现谁能获取什么信息、在哪个词上形成何种理解，以及可能的误读。

自然科学实测扩展：edna_capture展示颗粒随水流集中至滤膜，再经提取、扩增与参考库判读；qpcr_probe展示引物延伸及探针切开后的荧光；primer_specificity对比非目标在探针区或引物区受到区别时的扩增过程，均为固定原理示意，需核对是否符合本篇。edna_decay按visual的maximum、days、threshold（正有限数）及两条curves（label、initial、rate）画N(t)=initial×exp(−rate×t)；maximum覆盖起点与阈值。必须交代单位、参数来源及条件，曲线是模型重画，不冒充新增实测点。
