# 白话规格

白话的工作是补上论文省略的理解步骤。先判断读者卡在哪儿，再决定需要多少解释；没有句数或字数配额。

## 首选：让读者在脑中亲手走一遍

目标是**认知降维与心智对齐**：把作者脑中的对象、动作和因果关系，换成读者已经认识的东西，让读者能预测“下一步会发生什么”。不是给术语换个近义词，也不是写得口语化就算讲懂。

默认首选“**具体的人／物＋简单规则＋走一次过程**”，并用“**基本名词和动词**”检查每句话。先拿一个样本、一次交配、一段引文或一条记录走通关键步骤，再点出这就是论文所说的什么。数学与机制段尤其适合先演一轮：谁在哪里、手上有什么、做了什么、什么发生变化、为何得到这个结果。需要小数字时明说是教学演示，原文数据仍用原文值。

几种写法按读者卡点选择，可组合，不每段轮流套一套：

| 读者卡点 | 采用的办法 | 成稿应该补上的理解 |
| --- | --- | --- |
| 名词听不懂、对象看不见 | 熟悉场景的类比 | 先明确两边谁对应谁，再指出关键动作；比喻讲清后回到本文对象 |
| 不明白为什么需要这个办法 | 先演示不用它会发生的具体问题 | 展示一次漏算、误判或矛盾，再说明哪条规则解决哪一步；无需夸大成灾难或塑造“万能救星” |
| 知道各个名词，但过程连不上 | 具体对象按规则推演一次（首选） | 让读者看清输入、变化和结果，能够预测条件改变后哪一步会变 |
| 解释仍被术语堵住 | 拆成基本名词和动词（所有写法都要做） | 把“发生了调控”拆到谁增加／减少了谁、从哪里移到哪里、如何观察 |

**禁止用一个未解释的概念解释另一个概念（解释术语，不用术语代替解释）。** 写作中最常见的失误是：把英文术语翻成了中文，却用另一个统计或学科黑话去解释它。先把未解释的概念拆成“谁对什么数据／对象做了哪一步具体动作”，再将必要术语与这个动作对应，方便读者回到原文。已说明的“后验区间”“数据增广”等名称可以保留，不按禁词表删除。下面是释义方向，具体算法与推断强度仍按原文：

| 脱离解释时容易卡住的说法 | 按具体语境解释的方向 |
| --- | --- |
| “把未知位置从似然中积分掉” | “位置没观测到，就考虑它可能在哪里，按模型给这些位置的权重合并各处对应的记录可能性；具体计算不一定逐点枚举” |
| “大量后验质量落在高值区” | “结合模型和数据，偏大的取值仍占有较多可能性；具体占多少须看结果，不能把‘较多’自行改成‘过半’” |
| “边缘似然难以评估，导致信息准则复杂度惩罚失真” | “评分时固定哪些未知量、对哪些可能值取平均，会改变所评分的对象；先统一比较口径，再按本文方法判断模型表现” |
| “控制内生性造成的混杂偏误” | “例如措施优先给了原本表现更好的人，结果差异可能混入他们原有的优势；本文如何区分这些来源，要看实际研究设计。这只是内生性的一种情形” |
| “重复实验提高可靠性” | “同一样本分开做几次：若某条信号只偶然冒出一次，先不认作真实结果；反复出现的记录才进入后续判断” |

## 三级认知负荷分流（严防“难度倒挂”）

绝不能用同一种字数和力度对待所有段落。许多草稿在引言背景段写得生动好懂，一到方法推导、统计判据、多步机制或核心哲学辨析却突然缩成两句抽象概括——这叫**难度倒挂**，是带读的大忌。写前先判断本段属于哪一级：

1. **一级：过渡与铺垫段**（章首路线预告、常规样本罗列、简单承上启下）
   - 若对目标读者没有新障碍，简短交代衔接即可；通常一两句，不设句数配额。若所谓背景本身是理解难点，仍需解释。
2. **二级：常规实证／概念论述段**（研究缺口、实验分组、定性观察、讨论延伸）
   - 用“具体对象＋操作＋比较／因果”补上作者省略的一步中间推理。
3. **三级：高门槛卡点段**（核心数学公式、模型选择／拟合检验如 DIC/GoF、多步生化／物理过程、反直觉数据增广、高密度文本／概念思辨）
   - 给足解决卡点所需的篇幅。以下是常用写作路径，按卡点选择、组合或省略，不要求每段问句开头、固定三步或必配小数字：
     ① **找准直觉卡点**——像坐在旁边的师兄师姐一样，找出初学者最自然的疑问，可直接提出，也可在叙述中自然回答（例如：“读到这儿你可能会纳闷：既然第 2 轮根本没看见它，连它在哪儿都不知道，怎么算它离巡护路线有多远？”或“往真实观测表里硬塞 185 行全 0 的‘假个体’，难道不会把结果掺水吗？”）；
     ② **选择适合证据的具体推演**——拿 1 只动物、1 个细胞、1 份史料，或设两三个极简教学数字（明确写“举个例子”与原文实测值区分），在脑海里亲手算一遍／走一遍；历史、文学或理论段也可细读一句原文、比较两份材料或追踪一个反例，不为凑数字将阐释机械化；
     ③ **落回原文结论或公式符号**——推演通了，再指明刚才那一步就对应原文的哪个量或哪句判断。

## 独立公式（`eq`）与结果表（`table`）就地拆解

遇到独立成块的公式和结果表，不要把所有解释都挤在上下自然段里，让读者自己去对号入座。对核心独立公式和主要结果表，在 `translations.json` 中为对应 `eq`／`table` 块补充解释记录：

- **核心公式（公式白话拆解）**：先用一句话说清“这行式子到底在算什么变化”，再把式子里的关键符号逐个点名（代表什么实际东西、变大或变小时结果往哪边走），必要时点出会影响当前理解的边界（如“算出来的是非负累计风险 H，还不是 0 到 1 之间的概率 p”）。
- **关键结果表（读表抓手）**：面对十几行参数表，先告诉读者“第一眼先看哪两行／哪两列的对比”，指出关键估计、变化或有意义的对照，再说明它回答了正文哪个问题、哪一列不确定性范围提示我们别下过猛的结论。

## 用三层理解组织内容，不强制三块模板

1. **一句话直觉**：先说“它是在做什么／解决哪个麻烦”；合适时用“像什么”。不是所有概念都适合类比。
2. **关键运作**：让具体对象经过少量必要动作，通常两三步就能形成直觉；复杂过程按真实步骤讲，不删步骤凑成三步。每一步接上一步的变化，最后落到本文判断。
3. **边界与局限**：只有会改变当前理解时才补，例如配对并非随机时，刚才的推演哪一步失效。能融入解释就融入，不每段另加免责声明。

这是作者组织解释的顺序，不要求界面每段都显示“第一层／第二层／第三层”，也不要求每段一则故事。简短承接只讲承接。类比、失败场景和教学小例子用于还原关系，**不是新的证据**；历史与文学也不能被硬写成确定的机械因果或唯一解释。

写完做两次心智检查：①遮住术语，读者能否用自己的话说出东西怎样变化；②只改一个条件，读者能否指出哪一步会受影响。如果答案仍只是“更有效／更可靠／有启发”，检查中间是否还缺动作、比较基准或理由。这是编辑判断，不冒称做过读者实验。

## 白话怎么讲通

从具体记录、操作、现象或问题进入，沿着本段实际推理往下讲。可以用熟悉的情景或类比，但让它解释一件具体事情。短过渡段顺着前后文接过去即可，复杂段落则可以讲完整段。

例如 Royle 的“路线点等间距”，只写“点间距要规则，近似要足够细”是在重述要求。更有用的解释是：

> 电脑把弯曲路线换成一串坐标点来求和。前面的式子给每个点相同的份量，如果局部放了更多点，那一段路就被多算。等间距让每个点代表差不多长的一小段路，求和才是在近似整条路线的作用。

例如“未遭遇时位置缺失”，可以从记录本讲起：

> 手上有一张“个体×轮次”的0/1表，真遇到时才顺手记下坐标。没遇到那轮的坐标不是漏填，而是根本没观测到。模型因此要给未知位置一个分布，让它与已知位置、活动中心和路线一起受到约束。

这两个例子的共同点是把前提与方法接起来，而非套用同一个开场或强制比喻。

类比只承担必要的一段理解。例如用“挂锁／钥匙”说明别人可加密、只有持有私钥者能解密的直觉，并不因此讲完签名、认证或真实加密算法。论文没有涉及的环节不顺带扩成另一堂课。日常场景会让本篇关系更难懂时，直接用研究中的真实对象，往往更清楚。

## 逻辑要点怎么补充

白话帮助形成直觉，keys留下推理骨架。写出实质关系：哪项条件导致哪一步，什么证据支持哪种解释，两个结果为什么有差别。按本段关系决定条数。

先读完整段，说清它最后要把读者带到哪一步，再写keys。逐条检查：后一条是否用到了前一条的条件、发现或尚未解决的问题？若只是两个独立标签，把中间缺失的关系补上；原段是两项并列实验，则保留各自分支及共同问题，不编造连续因果。

例如路线离散段，不能只列“等间距”“强度转概率”；应说明每点等权→局部加密会多算→等间距统一路段份量→累计后转换为概率。但不能每段都套这四步：纯承接可能只需一句，复杂机制按实际过程展开。条数不是质量指标，禁止按配额填两个点或为了避开两个点硬拆句子。

通俗来自补足关系：从记录本、一次处理、可见反应或简单数值对比讲起，术语出现时说清它在做什么。避免“提供机制线索、连接候选路径”等抽象句独立充当整段解释；说明具体哪个处理改变了哪个指标、为什么接着查下一步。类比只解释对应环节，不堆口头禅、不把未证实机制说成事实。

- 空转：“说明离散点应规则分布”“介绍了几项孕妇研究”。
- 实质：“每点等权求和→局部点过密会多算→等间距统一代表的路段尺度”。
- 实质：“单次尿样与反复采样代表不同暴露窗口，因此研究人数不同并非结果差异的唯一来源”。

一条足够就一条；不要拆句凑数，也不要把白话重复缩写成几条。已有稿解释得好时保留它，只修实质错误。

## 条件与疑点放在哪里

把真正影响解释的条件写进推理本身：例如“在二维正态假设下”“作者据此推测”“测的是细胞蛋白表达”。具体数值带上对应单位、分母和比较条件。

trap仅用于正文尚未讲清、又会改变理解的具体疑点。已有解释足够时留空；原文自相矛盾、关键符号转录错误等在对应处点明一次。来源版本、核验范围等统一放页末，不每段附“不能证明因果/不能推广”等通用提醒。

## 编辑检查与消融

读完解释后，读者应能回答这个段落的具体“为什么”或“怎么回事”。字段齐全、固定条数、禁词命中和字数都不能代替这个判断。

若用户反馈生硬，选同一段保留对照：原稿；只去重复提醒；只补理解步骤；两项合并。一次只改变一个因素，比较是否增加了可理解的关系、是否减少无用打断。把这种对照写作称为编辑消融；未做盲评或读者试验时，不编学习效果分数。
