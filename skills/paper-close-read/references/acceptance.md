# 验收契约

独立验收遵守全局风险规则与预算；普通阅读页不因使用此技能自动加 agent。软件自检不等于原论文科学核验。

## 软件自检（可重跑）

`python scripts/selftest.py --work-dir <临时目录>/selftest`

覆盖：非 Royle 输入、标题前文本、多级标题、无标题输入、数字/公式负号保留、原表不替换、完整源串校验、缺译/重复 ID/错引用阻断、HTML 注入转义、图片内嵌与越界拒绝。结构校验保留数字、中文、否定和整句，不剥掉所有非英文字母或只匹配句首。

## 真实内容门

- 论文身份、版本、页码与范围真实；摘要/节选不宣称全文。
- 每条导读关键主张和自测答案有真实来源，且语义得到支持；来源“存在”不等于支持。
- 对原文原页检查关键数值/分母/单位/区间、公式与图表；OCR 有疑问时待核。来源串校验只能证明与 Markdown 一致。
- 图注、表头、附录及正文自然段的覆盖逐项核对；原始 Markdown 漏段无法靠翻译 ID 集合检测。
- 抽看不同难度的译文与白话，重点核查**防难度倒挂与术语解释**：全篇最难的方法推导、统计判据或理论思辨段是否找到具体卡点并用合适的推演、原句细读、材料对照或反例走通，核心独立公式与主要结果表是否配齐就地白话拆解／读表抓手；保留否定、条件、作者解释 vs 实证结果。迁移建议与项目决策分开。
- 不以一张截图、固定字段齐全或禁词正则证明“好读”或“学会”。

## 浏览器交互门（变更触及相关功能时）

用真实浏览器打开 file:// 单文件，禁网；至少桌面 1365px 与手机 390px：
1. 三路线、目录深跳、同 hash 重复点击、检索中英/数字、清空检索、已读与继续阅读。
2. 自测答案默认展开→手动收起→填写→展开→刷新恢复；笔记下载。
3. 选区→高亮/批注→编辑已有批注→重开浏览器进程恢复文字覆盖；不是只数 mark 个数。
4. JSON 导出→清理该论文记录→导入恢复；另一论文拒收且存储互不污染。
5. 文本变更/重复选中文字时不误贴；孤立批注可见且可导出。
6. 存储不可用时提示；缺失翻译的待补稿清楚显示。
7. 可选动画播放、暂停、逐帧、拖动、倍速、切路线暂停；静态帧可读，教学标签始终可见。
8. 桌面与手机检查选区工具条的高亮、写批注、关闭；批注角标刷新恢复正确。向下滚动显示回到顶部按钮，三路线均能返回顶部；减少动态效果下直接返回，工具条与浮动按钮不重叠。
9. 全页 scrollWidth 不大于视口（表格自身可横滚）、键盘可到达、控制台无运行错误、加载不发外部请求。

测试脚本、截图、profile 只放宿主指定临时目录或系统临时目录。若浏览器未实际跑通，则明确列未验证，不声称交互通过。

## 报告

改到记录、导入或交互时，补检：长段中途滚动→重开→换字号继续；整篇笔记/已读/复述/位置/批注完整往返，旧JSON兼容；两窗口冲突、错论文、重复导入及坏文件无半包写入；损坏/禁用/满额存储保留数据可导出；三分钟与十分钟真实讲解选字批注；搜索前后/退出回位、证据返回、原图适应/原尺寸及打印；对话框Esc和焦点返回、输入不被快捷键截获。仓库脚本check_reader_workspace.py与check_reader_navigation.py支持Chrome/Firefox/WebKit，按变更涉及的路径选择，不用相同单一路径次数替代覆盖。

列「质量/功能/创新性」发现、已修/未修、复现命令与结果。创新性评估是本实现的设计判断，不是首创认证；真实减负、理解和记忆效果需用户试读检验。


本版重点：主要正文每段有非空白话与逻辑要点，原文/译文和逻辑默认展开；18px计算字号与选择一致；旧的大字偏好不自动带入本版默认。元信息简列，主阅读进度不含书目/单位等。检验手动折叠仍可用，原文ID与已有批注锚点不因重排改变。

## 新文献迁移验收

遵循 generalization-examples.md 的内容审读：主线能连贯复述，10分钟补足中间步骤；白话解释实际困惑；要点形成原段真实推理或比较关系。记录检查过的段落和实质修订，不按要点条数打分。跨论文测试只能验证机制可用，不能保证下一篇解释自动优质。

模板改动后，用与现有两篇不同的合成输入完整走解析→校验→构建；不补丁修改生成HTML。新输入不带旧 claims/checks 也应正常生成叙事导读；漏 story 不能静默退回清单版。确认元信息无需填虚假白话，场景引用错误和同章重复实例被发现。相关动画在10分钟解释下直接操作，验证图文同屏和独立状态。

真实迁移验收应至少用一篇新真实文献走完整流程；合成用例只负责软件边界。原PDF与图表需实际查看，最终HTML需真实浏览器打开并操作。截图复查文字重叠、画面和阶段文字是否吻合；按钮通过不代表画面通过。重新构建应与交付HTML字节一致，并保存输入/生成器/产物摘要。发现问题在输入或通用生成器修复后重建，不对成品补丁。


历史/文学附加实检：对照出版商XML和PDF确认引文不重复、引文后文字不断、强调与注号保留，实点注号能到对应原注。选字高亮跨行内样式时仍应按原文字符定位。细读动图的quote须是链接原段的准确片段；逐步检查画中此时是谁、知道什么，不能只凭首中末像素不同认定语义通过。重要版本或年代冲突保存核对范围，不以来源覆盖齐全宣称逐字校对全部全文。


三分钟入门新增验收：新稿显示六步总览，背景/缺口/问题/方法/结果/结论各有具体回答和原文依据，全部无需展开或跳转即可读；逐卡检查**术语已解释**（操作与所得不依赖未经解释的名称，解释后可保留名称）与**结果口径清楚**（有恰当基准才比较；检查单位、分母、范围、时间窗，无对照不凑反差，`metrics`按需）。只看总览，按初学者节奏试读180秒，能否说出整篇研究在干什么？方法不只是名称，结果与结论分开，理论/历史/文学不伪装实验数据。六步总览通常约400–650中文字，计入指标卡阅读负担，按内容与读者调整，未做目标读者限时测试时不可宣称已证明所有读者三分钟学会。浏览器核对渐进引导按钮、六步顺序、对应证据跳转、窄屏阅读顺序及十分钟/逐段内容不受损。旧叙事稿仍可重建。

## 逐段词汇与 PDF

核对英文词形确实在对应原段、释义适应该段语境、没有固定条数凑词。PDF 需实际导出并目视检查中英文、公式、图表、跨页和归属；取消打印后原阅读与批注不变。完整步骤见 [PDF 与词汇规格](bilingual-pdf-vocabulary.md)。

## 原图完整性

对照原PDF逐页或出版商JATS独立图清单，逐一核对图号、子图、图注、坐标图例、正文位置及图片哈希。关键图在10分钟解释下原地显示/放大，动图不替代原图。实际PDF保留正文全部原图/图像公式，不重复导读图。没有独立清单不能声称完整，见 [原图规范](original-figures.md)。

原PDF原页窗口验收：鼠标实际拖动、拖手柄缩放、翻页、页面缩放和最大化还原；确认已核实页码定位正确，未核实入口只作浏览，关闭和操作不改变批注。原图放大窗亦可拖动缩放。

十分钟内容验收按reading-design.md逐节检查卡点、实际推进、所得与下一问题，记录具体节号与实质修订；做复述、删节/调序检查，允许真实并列分支。问句、固定条数、字段非空或按钮成功都不能代替此检查。

英文常显；译文/白话/逻辑各自默认展开，实际收起中文后英文仍可选字，其他开关状态不变；搜索命中收起的译文须展开，PDF仍输出完整中文。
