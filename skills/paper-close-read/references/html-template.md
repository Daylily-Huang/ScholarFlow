# 页面与能力边界

基础模板为assets/reader.css、reader.js；编辑式外观为editorial.css、editorial.js；机制动图为mechanisms.js与scripts/render_mechanisms.py。构建入口scripts/build_html.py；批注模块scripts/annotate.js。

## 已实现

- 两个内容区：mode-guide / mode-full；三档路线通过简短/展开导读与全文切换，不复制三份论文。
- 顶部路线、全文目录、来源块深跳、检索、已读标记与继续阅读。点击证据自动打开原文/译文；搜索可匹配中英文、讲解和数字。
- 原文译文在前，白话与逻辑在后；折叠区默认展开，可手动收起；手机改单栏，表格在局部滚动。
- 视觉沿用原版：暖白纸色、固定编号侧栏和当前章节高亮、章节细线、段落编号顶栏、齐边中英双栏、独立讲解底区；白话橙色、逻辑绿色、导航玫瑰色。英文正体衬线，中文18px，不用大块空白圆角卡片替代版式层次。元信息紧凑。
- 机制动图位于相关正文后，10分钟导读在对应讲解下面直接放独立播放器，不需要跳转；先提取主线与重难点，按mechanism-design.md规划后制作。
- 解释来源用 Markdown 行号及真实已核页码；无页码明确待核，不从固定印刷页计算。
- 可选自测输入，答案默认展开且可手动收起；阅读笔记导出 Markdown。
- 可选帧播放器：不自动播放，真实时长、逐帧、暂停、进度和倍速；切路线/进入后台暂停。
- 批注：稳定 data-ann-id + 精确选中文字与前后文；按 paperId 隔离，支持选区工具、Alt+H/Alt+M、编辑、删除、跳转、JSON 备份与导入、Markdown 导出。
- 内嵌 CSS/JS/MathML/栅格图，不发运行时网络请求。输出体积应实际检查；大动画是体积风险。

## 约束与可访问性

- 18px默认字号与16/18/20px选择、清晰对比、键盘焦点、原生 button/details/dialog 和屏幕阅读器标签；不靠颜色单独传意。
- 公式转换失败显示原始 LaTeX。缺图片或非法证据链接阻断构建。
- 批注仅支持同一稳定文本块，跨中英/公式不强行记录；失配保留在列表而非删除。文本重排不会仅因换行失配。
- localStorage 不是永久备份；file:// 不同浏览器行为可能不同。存储禁用/满额显示提示，可导出；JSON 导入拒绝论文不一致。
- 旧版缺少可靠论文身份的批注不自动混入当前论文，迁移时需先建立可靠对应关系。
- 当前没有聊天模型、云同步、听书、自动复习日程。打印只输出当前可见路线；不能把它当完整出版排版。

不要把测试挂钩或构建参数放进正常阅读流程。段落头部显示页码或来源定位，具体核验状态保留于页末“来源说明”和定位数据，顶部有入口。主要阅读区不重复展示通用核验提醒；影响该段解读的实际疑点就地说明。来源说明也默认展开。
