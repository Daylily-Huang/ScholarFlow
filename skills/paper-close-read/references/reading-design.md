# 面向“不想开始读”的带读设计

## 验收目标

读者能用自己的话回答研究问题、证据怎样得到、最重要限制和可能用途；不以页面长度、动画数量、按钮数或已读比例衡量成功。「无痛」是设计目标，不是已经证实的效果。

## 内容选择

- 前屏：一个具体问题 + 一个直接回答。先回答困惑，确实影响结论的条件写入句子；来源和核验说明集中在页末。
- 证据路线：先说清具体困境，再解释作者为什么需要下一步、这一步得到什么、它还留下什么问题。节点数随论证需要，不以章节标题或固定站数代替推理。方法论文讲输入如何经过假设与计算得到推断；实验论文讲对照怎样区分解释；观察研究讲变量关系及替代解释；综述讲不同证据怎样互补、冲突或留下缺口。逐段原文顺序保持原样，导读的教学讲述顺序可按理解需要调整。
- 图解围绕实际阅读难点写：先看哪里，看到什么，再怎样连到结论。无须每图固定写四项。
- 概念和公式按需解释：把量放回实际操作，讲清关系；类比会造成具体误解时才说明差异。
- note补理解步骤，keys提取推理关系，详见[白话规格](plain-language.md)。同一术语解释一次；复杂段落允许充分展开，过渡段允许简短衔接，不固定句数和条数。

## 有实际用途的创新

1. **解释—证据回路**：每条关键解释有可点击出处，读者觉得可疑时一步进入对应原文/译文。
2. **按困难分流**：只想知道值不值得读→入门；卡概念→术语/图解；要复现→全文方法与假设；不是凭画像自动推荐内容。
3. **条件改变自测**：可先收起默认展开的答案，再写自己的解释并对照，用“什么变了会失效”发现似懂非懂。
4. **迁移缺口清单**：把“可借鉴”具体化为需要哪些输入、满足哪些假设；不会变成项目采纳决定。
5. **可带走的笔记**：已读位置、自测和批注可保留/导出，重开文件后继续；更新导致批注失配必须可见。

这些是当前工程组合的改进方向，不宣称学术原创或已经优于现有产品。

## 真实效果如何试验（可选，不为这次维护扩大任务）

找少量目标读者分别使用普通 PDF 和本页，交换顺序并记录基础差异。观察开始阅读所需时间、是否能独立定位证据、复述准确性、隔日回忆与主观负担。小样本只能提供迭代线索，不能据此宣称普遍提升。若解释流畅却说不清限制，先改内容，不继续加功能。


## 当前阅读布局

默认18px并保留逐段精读主视图，同时在正文首屏上方放置轻量的渐进带读横幅（`3 分钟入门 → 10 分钟读懂 → 逐段精读`），并在三分钟和十分钟路线末尾提供下一步衔接按钮，消除初学读者一上来撞见英文和公式的畏难感。支持16/18/20px；正文对照、白话和逻辑直接可见（英文常显；`.translation`、`.plain` 与 `.logic` 各自默认 open，可独立收起），而公式块的原始 LaTeX 代码默认折叠，避免源码干扰阅读。核心独立公式与主要结果表就地附带「公式白话拆解」和「读表抓手」。题名、作者、单位和日期只作紧凑罗列；正文从摘要或首个实质章节开始。书目、致谢及声明放在末尾，不作为主要阅读进度。章节不存在就不补造。

## 三分钟入门：完整研究总览

目的：读者180秒内明白整篇主要做了什么，而不是只知道“这篇很重要”。默认六步顺序：

| 一步 | 必须讲出的内容 | 常见空话替换 |
|---|---|---|
| 背景 | 现实或学术上什么具体事值得关心 | 不只说“近年来备受关注” |
| 已有缺口 | 已有方法/解释知道什么，还解释不了什么 | 不只说“现有研究不足” |
| 核心问题 | 本文具体要弄清的关系、机制或解释 | 不只抄题名、写“探究影响” |
| 怎么做 | 谁/什么材料，经什么操作、比较或推理回答问题 | 不只报一个方法名 |
| 主要结果 | 最重要的1–3个发现，必要时给关键数字、单位和比较对象 | 不只说“取得显著结果” |
| 结论与意义 | 发现怎样回答问题，改变了什么理解、在哪个范围内成立 | 不只说“提供理论依据” |

上方一句话把主要工作说透；六步内容通常约400–650中文字，能独立读懂，无须先点链接、播放动画或背概念卡。最后一句将问题、做法与答案串回去。以初学者节奏试读，超过180秒先删支线，保留研究骨架。每步的字数不强求相同，方法和结果可以多占一点。

缺口与问题要相接，方法确实能回应问题，结果来自该方法，结论不比结果走得更远。旧研究没有明确指出的缺口，不补造“此前无人研究”；文学、历史可说本文增补哪些材料或读法。理论论文的方法说明概念怎样拆分、理由怎样推进，结果为论证所得；文学方法说明怎样从文本细节得出解读，不能拿小说剧情替代研究过程。

三分钟总览审读两件事：① 读者不必先懂陌生术语才能明白操作与所得，必要名称在解释后保留；不是按词表清空学术名词。② 结果有恰当基准时才对比，先检查对象、单位、分母、空间范围、时间窗与设计条件。可按需用 `overview.metrics` 突出关键量，无对照也可呈现最重要发现；不可比的量分别标明口径，不用相减、百分比或视觉排列暗示提升。指标卡的字数与认知负担也计入三分钟总览，通常无需重复六步里已说清的数字。

交付前只读总览，遮住正文：读者能否各用一句话回答这六个问题，并把它们连成一项研究？若仍不知道作者到底做了什么，应回源资料重写，不能靠再加一个“总结”框补救。


## 十分钟读懂：忠于原文的完整讲述

目标是把整篇研究讲成一段能连续读下去的故事：读者明白开头的困惑，跟上作者如何用材料与分析推进认识，最后理解证据怎样回答开头。故事化指讲述连贯，不指戏剧化、补写发现经历或把论文改造成更强的结论。

### 先写通，再分节

先在已有argument-plan里写出一篇能连续朗读的讲述稿，再按理解停顿划小标题、映射walkthrough字段。不要先定卡片数，再逐张填写背景/方法/结果；bridge和connection不能充当缺失推理的装饰。拿掉小标题、卡片边框与连接字段后，仅正文也应能连贯复述。

围绕一条真实的核心问题展开：从具体困惑进入，说明已有理解及其尚未解决之处；接着让读者明白本篇材料、设计或读法为何有助于回答问题；随证据说明认识如何推进、还有什么未解，最后回到开头，交代得到的回答及其范围。这是讲述思路，不是各篇必须填满的固定剧情；不强求意外结果、反转或成功解决。方法文讲记录如何经假设与计算得到推断，综述讲证据如何互补/冲突，历史/文学/理论讲材料与解释如何相互支持或受限。

下一段要承接读者当下已知道什么、还不知道什么；需要中间概念、比较基准或分析步骤时在此解释，不能跳过去靠结论补桥。节奏随理解难度分配：普通背景简洁，核心分析放慢，沿同一对象或材料举例。不同例子需交代变化的对象与条件；不要求每节同样长、同样多问句。真实并列证据可明确分支再汇合，也可承认它们只能分别回答问题的一部分，不强行串成时间或因果链。

### 原文证据是讲述边界

- 可调整讲解顺序、解释术语和省略的基础知识；原文正文/原图不改序，教学重排不冒充作者实际研究或发现的先后。不能虚构作者动机、内心活动、研究经历、已有研究的失败或领域空白。原文未说明目的时，可讲分析的作用，不能替作者断言当时为何选择。
- 保留对象、比较基准、时空范围、适用条件、数量和不确定性。相关性不写成因果，统计交互不直接写成作用机制，模型投影不写成必然未来，作者解释/假说不写成已经证实，个案/局部结果不扩大到全部对象。原文自身的强表述如实归属作者，并说明设计实际可支持的范围。
- 每个承重判断和叙事转折在撰稿计划中能回指具体来源，检查该来源是否真正支持这句话，而非只检查refs存在。保留作者提出的替代解释、反例、矛盾或会改变结论的限制；未解决的地方可以停在不知道，不为结尾完整替作者解决。
- 教学例子、类比或补充背景帮助解释，不能作为本文的新证据；必要时在引入处自然说明其教学身份及关键差异，不每段堆免责声明。原文不足以支撑的桥接，改成明确的比较/待答问题、补适用来源并标明背景，或删掉，不能用“所以/因此”硬接。

### 图与问题随讲述出现

保留现有SVG/Canvas等解释动画、原文结果图和适用反问；不限定底层绘图技术。先交代为什么看、看哪里，再在对应讲解下面原地展示，接着解释看到了什么及它能支持哪一步。动图演示机制或教学条件，原图呈现实际证据；二者的对象、条件和证据强度一致，不能用动画把假设画成已证因果。反问只放在读者真实可能卡住的转折，随后用材料回答；原文无答案就如实保留，不为了悬念故意隐瞒已说明的关键信息。

### 两条验收线同时满足

1. 连贯性：遮住原文、拿掉小标题和独立连接字段，仅读连续正文，能否复述为何研究、为何这样做、每组证据怎样改变认识、最后如何回应开头？哪里需读者自行补桥就回到正文补足。删节/调序只用于找重复与断点，不以并列证据可交换为缺陷。
2. 忠实性：逐项对照承重句及转折的来源，检查关系强度、条件、基准和归属。讲述是否为了顺畅而偷换对象、制造因果、掩盖反例或填补未知？有就退回改写。流畅、像故事或读起来有趣，不能替代这条审读。

在既有计划记录具体断点、承重句、来源和实质修订即可，不新增成套表单；程序字段与链接校验不能判定叙事连贯或推断是否适度。未做真实读者测试时，只报告实际内容审读范围，不宣称已证明人人十分钟学会。
