## 2. 详细维度说明与选项设计

### D1: 研究目标与产出定位 (`CRITICAL`)
- **[A] (Recommended)** 学位论文开题 / 领域系统综述背景调研 — *[依据：全面梳理学术脉络，保证方法可审计与高召回]* `[高置信度]`
- **[B]** 特定技术路线 / 实验方案选型 — *[依据：聚焦具体实验参数与操作协议]* `[中置信度]`
- **[C]** 前沿学术争议 / 竞争假说事实核查 — *[依据：针对对立流派文献进行定向筛查]* `[中置信度]`

### D2: 核心研究问题与因果命题 (`CRITICAL`)
- **[A] (Recommended)** 探索性机制 / 因果关联命题 — *[依据：因果机制研究最具深度学术价值]* `[高置信度]`
- **[B]** 现状与基线评估（时空分布、丰度或参数现状） — *[依据：基线摸底型调研适用]* `[中置信度]`
- **[C]** 方法学有效性验证（新旧方法评测对比） — *[依据：评测新型算法或实验平台适用]* `[中置信度]`

### D3: 目标实体与概念范畴 (`CRITICAL`)
- **[A] (Recommended)** 严格限定于单一目标实体（及其同义词/分类变更名） — *[依据：杜绝跨领域无关文献扩散，保障准确率]* `[高置信度]`
- **[B]** 包含近缘实体 / 同族对照实体 — *[依据：单一实体文献极度匮乏时拓宽边界]* `[中置信度]`
- **[C]** 泛化至同类方法/通用范式全集 — *[依据：仅关注通用技术本身]* `[需权衡]`

### D4: 纳入标准与边界 (`CRITICAL`)
- **[A] (Recommended)** 具备完整实证数据、明确实验/调查设计与定量结论 — *[依据：保障下游可提取与可定量合成]* `[高置信度]`
- **[B]** 包含理论推导、概念模型与评论性观点 — *[依据：理论推演型综述适用]* `[中置信度]`
- **[C]** 全谱高召回（只要提及关键词即粗筛纳入） — *[依据：冷门探索适用]* `[需权衡]`

### D5: 排除标准与禁忌红线 (`CRITICAL`)
- **[A] (Recommended)** 排除纯新闻科普、无数据评论、掠夺性期刊与非正式观点 — *[依据：严守学术同行评审门禁，抵御低质噪声]* `[高置信度]`
- **[B]** 允许经过权威机构认证的高质量预印本，但排除科普与社论 — *[依据：前沿爆发性领域适用]* `[中置信度]`
- **[C]** 仅排除纯商业广告与完全无关学科 — *[依据：最低限度过滤]* `[需权衡]`

### D6: 概念拓展与近义词策略 (`HIGH_IMPACT`)
- **[A] (Recommended)** 标准概念矩阵构建（核心词 + 英文正名 + 缩写 + 核心方法） — *[依据：PRISMA-S 规范推荐，平衡查全与查准]* `[高置信度]`
- **[B]** 极简核心词检索（仅使用标准主词） — *[依据：快速量级探测]* `[中置信度]`

### D7: 地理与空间范畴 (`HIGH_IMPACT`)
- **[A] (Recommended)** 不设地理限制（全球文献，关注普适性机制） — *[依据：现代科学普适性偏好]* `[高置信度]`
- **[B]** 限定于特定国家 / 地理生态大区 — *[依据：具有明确地域政策或本土属性]* `[中置信度]`

### D8: 时间跨度与历史回溯 (`HIGH_IMPACT`)
- **[A] (Recommended)** 近 10 年前沿为主 + 领域奠基性经典文献追溯 — *[依据：兼顾前沿进展与经典范式源流]* `[高置信度]`
- **[B]** 近 5 年极高前沿（专注于最新突破） — *[依据：爆发式发展学科适用]* `[中置信度]`
- **[C]** 全历史无截断 — *[依据：通史与范式演变适用]* `[中置信度]`

### D9: 文献类型与同行评审门槛 (`HIGH_IMPACT`)
- **[A] (Recommended)** 同行评审学术期刊研究论文优先 — *[依据：科研循证金标准]* `[高置信度]`
- **[B]** 期刊论文 + 权威博硕学位论文 + 顶会论文 — *[依据：补充未完全发表的方法细节与原始数据]* `[中置信度]`

## 3. 提问生成与默认规则

1. 系统在启动时根据用户输入的任务描述，自动将明确声明的项识别为 `[INFERRED]`；
2. 在未决维度中挑选未声明的 `CRITICAL` 维度（D1-D5）和关键 `HIGH_IMPACT` 维度（D6-D9），严格控制提问总数在 **3~5 题**；
3. 其余 `DEFAULTABLE` 维度（D10-D14）自动按选项 A 的推荐值应用，打上 `[DEFAULTED]` 标签写入最终快照；
4. 提问输出后，**Agent 必须执行 STOP Rule**，等待用户回复。
