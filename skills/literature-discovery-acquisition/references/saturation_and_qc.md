# Stage 7: 检索饱和度评估与质控自检清单 (Saturation Assessment & Quality Control)

## 一、检索饱和度评估 (Search Saturation Assessment)

在严谨的系统化文献检索中，研究者必须以**边际递减法则**来客观度量何时可以停止检索，而不是主观感觉“差不多搜够了”。

### 1. 轮次边际收益跟踪模型
检索必须按轮次记录新增量，构建边际收敛表：

| 轮次 (Round) | 检索方式 / 策略来源 | 检出总数 (Retrieved) | 去重后新增 (New Deduped) | 初筛纳入/待定 (Included/Uncertain) | 边际贡献率 (Marginal Yield) |
|:---:|---|:---:|:---:|:---:|:---:|
| **Round 1** | 核心与扩展检索式 (Q01–Q02) | 240 | 215 | 68 | 基线 (100%) |
| **Round 2** | 分类群与方法扩展式 (Q03–Q04) | 95 | 32 | 14 | 20.6% |
| **Round 3** | 种子文献反向引文追溯 (Backward) | 86 | 19 | 8 | 11.8% |
| **Round 4** | 种子文献正向施引追踪 (Forward) | 52 | 7 | 3 | 4.4% |
| **Round 5** | 核心作者与相似论文追踪 (Author/Similar) | 28 | 2 | 1 | 1.5% |

### 2. 边际饱和停止准则 (Stopping Criteria)
满足以下条件之一时，可判定当前检索策略达到收敛：
1. **绝对边际值低于阈值**：连续两轮追踪或扩展中，单轮新增初筛有效文献数 $\le 2$ 篇；
2. **相对边际率收敛**：最新轮次的新增有效文献占首轮比例 $< 5\%$；
3. **闭环引用出现率饱和**：引文追踪中发现的新文献，有 $> 80\%$ 已经在前序轮次中被检出或去重。

### 3. 饱和度合规声明标准
- ✅ **标准声明**：“在当前设定的检索词矩阵、数据源与引文追踪路径下，新增有效文献已降至边际收敛水平（第 5 轮仅新增 1 篇），本轮文献检索已接近饱和。”
- ❌ **严禁声明**：“该领域的文献已全部找到”、“没有其他相关研究了”。

## 二、PRISMA 风格文献流转审计 (PRISMA Flow Tracking)

系统检索报告必须提供透明的流转数据账本：

```text
[识别阶段 (Identification)]
  ├── 开放学术 API (OpenAlex / PubMed / Europe PMC / bioRxiv): n = 335
  ├── 学术 Web 检索与扩展: n = 92
  └── 种子文献引文网络追踪: n = 166
      └── 总共识别记录数: N = 593

[去重阶段 (Deduplication)]
  ├── 移除重复记录数: n = 212
  └── 独立唯一候选文献: N = 381

[初筛阶段 (Screening)]
  ├── 依据题录与摘要排除文献: n = 286 (记录分类排除原因)
  └── 初筛合格文献库: N = 95
      ├── 明确纳入 (Included): n = 78
      └── 待定需全文核实 (Uncertain): n = 17
```

## 三、检索局限性与缺口声明 (Search Gaps & Limitations)

每一份交付报告中必须强制包含检索缺口与局限性声明：
1. **未直接覆盖的数据库**：明确列出受限于权限未能直接调用的数据库（如 CNKI、万方、Web of Science 核心合集、Scopus 等）；
2. **语言偏倚 (Language Bias)**：若未覆盖非英语、非中文的欧洲/小语种文献，必须明确指出；
3. **发表偏倚 (Publication Bias)**：警示未发表的阴性结果（Negative results）可能未被收录；
4. **人工补检指引**：附上为商业数据库定制的人工补检式，提醒研究者在学校/科研机构局域网内进行最终复核。

## 四、12 项输出前质控自检清单 (Pre-Delivery QC Checklist)

在向用户提交最终结果或生成交付文件前，Agent 必须对照以下 12 项硬规则逐一自检。**若有任何一项不满足，必须立即回退纠正**：

- [ ] **Check 1**：是否执行了 Stage 0 的 Grill-Me 环节并锁定了检索边界协议？
- [ ] **Check 2**：是否构建了至少包含 2–4 个正交维度的 Concept Matrix？
- [ ] **Check 3**：是否对美英拼写变体、同义词与上位/下位分类群进行了扩展？
- [ ] **Check 4**：是否生成并使用了多组针对性检索式，而非单一长式？
- [ ] **Check 5**：是否输出了四层级重点期刊推荐表及数据库过滤代码块？
- [ ] **Check 6**：是否调用了至少两个独立数据源，并如实标注了实际检索与未检索库？
- [ ] **Check 7**：是否执行了规范的四级级联去重，并保留了多来源记录？
- [ ] **Check 8**：初筛是否严格划分了 Include / Exclude / Uncertain，并保留了所有 Uncertain？
- [ ] **Check 9**：是否挑选了 Seed Papers 并执行了双向引文追踪？
- [ ] **Check 10**：是否提供了边际收敛饱和度数据，且**未**使用“找全所有文献”等绝对化词汇？
- [ ] **Check 11**：是否存在任何由摘要脑补实验步骤、PCR 体系或虚构 DOI 的违规行为？
- [ ] **Check 12**：是否提供了标准化检索缺口声明与可导出的文献清单文件？
