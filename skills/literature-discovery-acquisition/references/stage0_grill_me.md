# Stage 0: 研究问题拆解与 Grill-Me 前置交互规程 (Research Question Parsing & Grill-Me Protocol)

## 一、规程目的与核心原则

在学术文献检索中，用户给出的初始 Prompt 往往是宽泛或存在隐性前提的（例如：“帮我搜一下粪便 DNA 鉴别野生动物个体的论文”）。如果未经澄清直接搜索，将导致严重的检索偏差（如检出大量不可用的综述、遗漏英文顶刊、检索年份不符需求等）。

**Grill-Me 交互门禁的核心目标**：
1. **主动展示专业性**：不让用户面对空白问卷，而是基于输入自动给出『研究范围初稿』、『概念矩阵初稿』与『推荐重点期刊』；
2. **精准收拢检索边界**：通过针对性的结构化多选/单选提问，让用户对文献类型、时间范围、语言、数据源与检索模式做出一键决策；
3. **建立审计基线**：所有确认的边界参数自动固化至检索日志中，作为后续纳入/排除初筛的基准。

---

## 二、Stage 0 自动化解析维度 (Parsing Dimensions)

接收到用户请求后，Agent 必须在后台首先解析出以下 10 个关键维度：

| 维度 | 英文标识 | 默认假设（若用户未明示） |
|---|---|---|
| **核心科学问题** | Core Research Question | 提取核心自变量、因变量与研究目标 |
| **研究对象/生物类群** | Target Entity / Taxon | 精确对象（种名/概念） + 上位/同级类群 |
| **实验/研究方法** | Method / Technology | 分子标记、统计模型、取样方式等 |
| **时间跨度** | Publication Date Range | 默认不设下限，优先关注近 10–20 年 + 经典奠基文献 |
| **地理/空间范围** | Geographic Scope | 默认全球（若研究对象具特有性，如中国特有种，则标记重点区域） |
| **文献类型限制** | Document Types | 默认包含同行评议研究论文（Articles）；综述（Reviews）单独标记用于引文追踪 |
| **学位论文与灰色文献**| Grey Literature / Theses | 默认：博士/硕士学位论文作为重要补充，会议论文视学科而定 |
| **语言限制** | Language Scope | 默认：中英双语检索（英文覆盖国际主流，中文覆盖本土实证） |
| **检索深度模式** | Search Mode | 默认为 `Deep Search`（系统性全面检索），可选 `Quick Search` |
| **预期交付物** | Expected Output | Markdown 完整检索报告 + 候选文献 CSV + BibTeX 导入文件 |

---

## 三、Grill-Me 交互执行三步走流程

### Step 1：自动生成三大初稿推荐 (Auto-Drafting)
在向用户提问前，必须在对话中清晰呈现初步解析结果：
1. **研究范围与边界初稿**（核心对象、方法、目标）；
2. **推荐检索词矩阵初稿**（Concept A/B/C/D 的核心词与扩展词）；
3. **推荐检索重点期刊列表**（第一层级至第四层级的代表性刊物）。

### Step 2：发起针对性决策提问 (Grill-Me Questions)
Agent 必须根据初稿中存在的不确定项，向用户提出 2–4 个聚焦的结构化问题（每个问题必须提供推荐选项，并以 `(Recommended)` 标注）。

**核心提问矩阵库**：
- **Q1 [检索模式与深度（核心第一必问项）]**：
  - `(Recommended) Deep Search（系统性深度检索）：执行完整 8 阶段流水线（多数据库全检索、正交概念矩阵全展开、候选量≥30篇多子代理并发初筛、核心文献双向引文追踪、边际饱和度收敛评估、PRISMA-S 16项机器质检与 OA 全文下载+Zotero沉淀）。耗时较长、查全率极高。适合：硕士/博士毕业论文开题、SCI文献综述撰写、国家自然科学基金等科研立项申报。`
  - `Quick Search（快速精准探索）：轻量执行 4 阶段极速流水线（聚焦高精核心检索式 + 四层级重点期刊精准过滤），极速获取 10–30 篇顶刊代表作与核心开源全文，声明“非系统性探索”，严格控制上下文预算（<15 KB）。适合：组会速览研讨、前沿热点快速摸底、快速概念验证。`
- **Q2 [硕博士学位论文专项需求（核心第二必问项）]**：
  - `(Recommended) 需要检索硕博士学位论文（中英文均覆盖，包含中国知网 CNKI 优秀博硕士、万方、ProQuest PQDT 及全球开放博硕 OATD；可获取详尽原始实验参数）`
  - `仅需要中文硕博士学位论文（重点覆盖国内知网/万方与重点高校学位库）`
  - `仅需要英文硕博士学位论文（覆盖 ProQuest PQDT 与全球高校机构知识库）`
  - `不需要学位论文，仅检索同行评议期刊论文与预印本`
- **Q3 [语言与文献类型边界]**：
  - `(Recommended) 中英双语全覆盖（含同行评议研究论文 Article 与权威综述 Review）`
  - `严格仅限英文同行评议期刊论文（聚焦国际核心 SCI/Scopus 索引文献）`
  - `全类型覆盖（额外包含行业技术调查报告、会议论文与预印本）`
- **Q4 [时间跨度限定]**：
  - `(Recommended) 全时段覆盖（包含历史奠基文献，重点高亮近 10 年最新进展）`
  - `仅聚焦近 10 年研究（2014 年至今）`
  - `仅聚焦近 5 年最新突破（2019 年至今）`

### Step 3：锁定检索协议并生成协议快照
用户确认或调整后，Agent 必须输出一段明确的【已确认检索协议快照】，示例：
```markdown
> **已确认检索协议快照**：
> - 模式：Deep Search
> - 语种：中英双语
> - 类型：Journal Articles + Reviews + Dissertations
> - 时段：All years (重点标定 2014–2026)
> - 数据源调度：OpenAlex + PubMed + Europe PMC + Web 深度探测 + CNKI 补检式生成
```
只有在协议快照确认后，才正式流转至 Stage 1 概念矩阵锁定与检索执行。
