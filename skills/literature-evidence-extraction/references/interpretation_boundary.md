# 事实抽取与科学解释边界隔离指南 (Interpretation Boundary Protocol)

## 一、为什么必须在物理上隔离“事实”与“推论”？

在学术文献处理中，大模型最容易犯的错误之一就是**将“文献的客观事实”与“AI 自己的分析评论”熔焊在一起**：
- ❌ 在事实表格的提取值栏写出：`“退火温度为 53°C，该温度偏低，可能会增加非特异性扩增的风险……”`
- ❌ 在事实说明栏写出：`“虽然作者未写 BSA，但根据粪便 DNA 含有高浓度腐殖酸的常识，作者实验室很可能私下添加了 BSA……”`

这种混合输出不仅会破坏科研数据的可复现性与严肃性，更会严重误导后续的实验设计与论文写作。

---

## 二、双阶段硬隔离原则 (Physical Segregation Rule)

```text
┌─────────────────────────────────────────────────────────────┐
│ 【受控安全区】：事实抽取与验证 (Phase A + Phase B)         │
│  - 严格限制在 Evidence Table 内部                           │
│  - 只能输出原文字面值、最简原句、E1-E4级别与页码            │
│  - 严禁出现任何未经证实的“我认为”、“可能是”、“建议”        │
└─────────────────────────────────────────────────────────────┘
                               │
                       严格防火墙 (Firewall)
                               │
                               ▼ 仅当用户在 Stage 0 明确要求解释时才允许生成
┌─────────────────────────────────────────────────────────────┐
│ 【独立分析区】：科学解释与推论 (Phase C - Interpretation)   │
│  - 必须以独立的一级/二级标题单列在报告末尾                  │
│  - 明确标注本节为“AI 派生分析”，绝非原文事实记录           │
│  - 讨论方法局限性、横向对比评价、对本课题的实证启发        │
└─────────────────────────────────────────────────────────────┘
```

---

## 三、合规判定黄金准则 (The Gold-Standard Deletion Test)

> **黄金删除测试 (Gold-Standard Deletion Test)**：
> **如果将报告后半部分的 `### 科学解释与分析推论` 章节整段删除，前半部分的 `Evidence Table` 是否依然是一个完全自洽、毫无主观色彩、可以直接导入数据库的纯客观事实账本？**
> - 若是，则判定完全合规；
> - 若删除推论章节后，发现事实表格中残留了评价性断言或常识推测，则一票否决！

## 四、合规示例对照 (Compliant vs Non-Compliant)

### ❌ 违规反模式：推论污染事实表
```markdown
| Field | Extracted Value | Evidence Quote | Notes |
|---|---|---|---|
| Mcr-04 Allele Range | 225–241 bp (作者分型可能有偏小趋势) | “Locus Mcr-04 ranged from 225 to 241 bp.” | 该位点在黑麂中通常在 230 bp 以上，作者可能没有校准好分型标准，建议重跑。 |
```
*审查员裁决：**REJECT**。在事实 Value 与 Notes 栏掺入主观推断。*

### 💡 科学解释与分析推论 (Phase C: Scientific Interpretation)

1. **等位基因跨度评估**：
   - 原文报道的 225–241 bp 跨度为 16 bp，符合二核苷酸重复微卫星位点的理论步长（8 个等位基因梯度）；
