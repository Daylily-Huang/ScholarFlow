# 示例：挑战已有假说（推敲模式）

> **虚构演示**。人物、数据、文献与结论均为编写示例所需而虚构，不构成研究结论或建议。
> 本示例展示 `examine` 模式，并演示三件容易出错的事：**外部意见不等于证据**、**独立评估的分歧如何交回用户**、**用户维持原判时如何如实记录**。
> 场景假定已完成 Stage 0，故省略配置轮次。

## 场景设定

- 用户（虚构）：同一课题的后续阶段，已有成形命题。
- 起点命题（v1）："在固定样地内，更新苗的数量与高生长随郁闭度升高而下降。"
- 外部输入：导师（虚构）认为主因是**土壤压实**，建议挖剖面测容重与孔隙度。
- 用户已声明边界：不愿跨生长季野外；不愿补采土壤样品。

---

## R1｜命题性质与比较基准（P1）

**主持人 · 视角切换**
这是已有论断，按推敲模式处理（`maturation = DEVELOPING`）。先明确它是关联还是因果，以及比较基准。

贡献（`AI判断`）：现有表述用的是"随……下降"，属**关联性**陈述；但"土壤压实是主因"隐含**因果**主张。两者不能混谈。此外"郁闭度"要与谁比较——同一林分内部，还是不同林分之间——目前不清楚。

焦点问题：你想检验的是同一样地内部苗高随郁闭度的变化，还是不同样地之间的差异？

> **规则落点**：P1 命题化（性质 + 基准）。命题性质决定后续允许的判定类型：关联性命题不得用机制推理替代观测。

**用户（虚构）**：样地之间。同一块地里的小苗我数得太少，分不出什么。

## R2｜承重前提表（P2）

**前提与证据审查者 · 视角切换**
按"样地之间比较"这个基准，命题至少依赖三条承重前提，其中一条目前没有任何依据。

贡献（`AI建议` · 承重前提表）：

| 前提 | 类型 | 脆弱性 | 判定它需要什么观察 |
|---|---|---|---|
| 各样地的郁闭度读数口径一致、可比较 | `METHODOLOGICAL` | HIGH | 同一方法在同一批样地的复测记录 |
| 各样地除郁闭度外的影响大致可比（土壤、坡位、经营史） | `EMPIRICAL` | HIGH | 各因素的记录或分层 |
| 郁闭度是限制因子，而非伴随特征 | `EMPIRICAL` | HIGH | 能分离光照与其他限制的比较 |

贡献（`AI建议` · 最强反例场景）：若样地之间同时存在土壤紧实度差异，且紧实度与郁闭度同向变化，则"随郁闭度下降"这一关联无法归给光；此时命题对该机制既不支持也不否证。改判条件：若能找到郁闭度相近而紧实度不同的样地对照，本条的脆弱性下调。

焦点问题：你手上有没有哪几块样地，郁闭度差不多但地表状况差别比较明显？

> **规则落点**：P2；`PREMISE_SURFACED`。反例以"若……则……"给出，并附改判条件；未把"导师说是压实"当作依据。

**用户（虚构）**：有两块是这样。不过我没测过紧实度，只有印象。

## R3｜外部意见的处理（P0）

**主持人 · 视角切换**
导师的意见需要单独登记：它是**外部意见**，既不是你的决定，也不是证据。

贡献（`AI判断`）：已记 `external_opinion`（来源：导师，经你转述，未核验）。挖剖面测容重与孔隙度需要补采土壤，与你已声明的"不补采"冲突 → 该方案标为**超出已知资源**。

焦点问题：你是要把"土壤压实"登记为一条正式的竞争解释，还是只记为一条意见？

> **规则落点**：P0（外部输入）；决策交回用户。**外部意见不得作为决定作者，也不得升级为证据。**

**用户（虚构）**：登记成竞争解释吧，我觉得值得一起考虑。但挖剖面先不做，我得再想想。

## R4｜可观察预测与改判条件（P3）

**推论与验证者 · 视角切换**
既然有两个解释在争同一批观察，就需要一条能把它们分开的预测。

贡献（`AI建议`）：两条可区分预测 ——
- `P1`：若光限制为主，苗高应随受光条件**单调**上升，形态表现为茎细长；
- `P2`：若压实为主，更新失败应集中在贯入阻力高的位置，与受光条件**无关**。

最小判别设计草案：在样地内部按受光位置分层，同时记录苗高与地被状况；**区分不了**"母株环境差异"这一类解释。重复数、观测时长、统计方法**待补**。

焦点问题：这两条预测里，哪一条你手上的记录已经能部分对上？

> **规则落点**：P3；进入前已有 `PREMISE_SURFACED` 与 `DISCRIMINATION_ADDED` 两个发展信号，配额满足。明确写出"本设计区分不了哪一个"。

**用户（虚构）**：P1 好像对得上，林窗边的确实高一些。P2 我没法看，没测过哪里紧。

## R5｜独立评估与分歧（P5）

**主持人 · 视角切换**：可以，我按你之前的要求启动一轮独立评估，两个子任务、计入评审批次。评估目标：当前命题 v2 的逻辑结构与两个解释的可区分性；输入为命题原文、你的资源约束与已有读数。

焦点问题：是否现在启动这一轮独立评估？

> **规则落点**：P5 与输入白名单；先说明评估目标与范围。**独立评估的启动、提交与分歧判定都不构成用户轮次。**

**用户（虚构）**：启动吧。

**前提与证据审查者 与 替代解释探索者 · 独立 Agent 评估**（两个任务分别提交，提交前互不可见）

- **前提与证据审查者 · 独立 Agent 评估**：`verdict = BOUNDED`。最脆弱处是"郁闭度读数可跨样地比较"与"缺少逐样地配对记录"；最强反例 `NONE_FOUND`（所查范围：仅输入包，包内无原始记录）。改判条件：提供逐样地配对读数，或证明不同口径读数排序稳定。
- **替代解释探索者 · 独立 Agent 评估**：`verdict = CHALLENGED`。提出可区分的替代机制"反复顶端取食抑制"，判据为顶芽缺失与多主茎等形态特征，且加测不涉及补采土壤、不涉及跨年。改判条件：高生长随受光单调上升且无失顶形态，则接受光限制为主。

分歧判定（由确定性程序计算）：`verdict` 不同（`BOUNDED` / `CHALLENGED`）、承重前提重合度低、反例不同 → **`HIGH_DIVERGENCE`**。共同点：两者都指向"现有郁闭度读数不可比"这一缺口。真正分歧：现有数据下命题是**不可检验**，还是**已被一条可区分机制挑战**。不投票、不取平均。

贡献（分歧交回）：两个评估者各自给出了愿意改判的条件，且都指向同一类证据——能区分取食与光限制的形态判据。

焦点问题：你希望怎么处理这个版本——保留原表述等待证据，还是改成一条能在你现有条件内检验的表述？

> **规则落点**：`HIGH_DIVERGENCE` 交由确定性程序判定 + 分歧交回用户；未宣称评估通过，也未调和两种判定。

**用户（虚构）**：先别改。我还是觉得光的问题更大。被啃这个我记一下，师兄以前好像提过，我记不清了。要是只用现有的东西、不用再跑一年也不用再取土，那我可以照着试。

## R6｜收尾（P6 / CHECKPOINT）

**观点修订引导者 · 视角切换**

贡献（三段式）：
- **保留**：你仍认为光的作用更大；该判断既未被检验，也未被否定。
- **修改**：自本轮起把"取食抑制"登记为可区分观察项，仅列 `待验证假说`，采纳记录为 AI 建议、由你确认保留在清单中。
- **未决**：①郁闭度读数跨口径不可比；②压实深度与基准未定义且受"不补采土壤"约束；③"更新不良"缺少基准；④小样方布设代表性不可复原。

说明：按 S1，连续两轮未新增进展信号，进入检查点；`stop_reason = CHECKPOINT_REACHED`。命题仍为未解决状态，本会话**没有**形成最小验证方案，因为全程未进入 P3 的可检验形式确认。

焦点问题：上面这三段记录，是否与你的理解一致？

> **规则落点**：P6；收尾前检查：本会话已进入 P3（R4），但未完成可检验形式确认，因此小结只写"缺哪一步"，不输出最小验证方案。**未宣告问题解决。**

**用户（虚构）**：差不多。我先回去翻翻本子上有没有记顶芽那些。

## 本示例的规则落点汇总

| 规则 | 在本示例中的体现 |
|---|---|
| 命题性质先定 | R1 区分关联性表述与因果主张，明确比较基准 |
| 外部意见 ≠ 证据 ≠ 决定 | R3 记 `external_opinion`，方案标"超出已知资源"，是否采纳由用户定 |
| 发展配额 | R4 进入 P3 前已有两个发展信号 |
| 独立评估隔离 | 输入包只含命题、约束、已有读数；不含主持人历史与其他评估者结果 |
| 分歧交回用户 | `HIGH_DIVERGENCE` 由一个判别问题交回，不投票、不调和 |
| 用户维持原判 | R6 如实记录"保留"及其理由，不做二次劝说 |
| 收尾诚实 | 未形成最小验证方案就如实说明缺哪一步；不宣告问题解决 |
