# ScholarFlow Unified Uncertainty Model (通用不确定性模型)

> **Status**: Core Grounding Standard  
> **Applicability**: Literature Extraction, Evidence Verification, Cross-Paper Synthesis  
> **Target**: Ensure deterministic, auditable labeling of epistemic uncertainty across all disciplines.

---

## 1. 五态不确定性分类学 (The 5-State Taxonomy)

在科研证据提取与综合过程中，所有无法确认为单一、高可信确定事实的表述，必须严格归入以下五个标准状态之一：

```text
┌───────────────────────────────────────────────────────────────┐
│                    Epistemic Status Space                     │
├──────────────────┬────────────────────────────────────────────┤
│ SUPPORTED        │ 充分确立：原文原句完全支持，无歧义           │
├──────────────────┼────────────────────────────────────────────┤
│ NOT_REPORTED     │ 全文未提：文献正文/表格/附录完全未提及此项   │
│ AMBIGUOUS        │ 表述歧义：原文有提及但存在多重解释或条件不明 │
│ UNKNOWN          │ 本质未知：当前科学界或作者明确声明为未知     │
│ CONTRADICTORY    │ 内部矛盾：文献内部不同位置给出互相冲突的数据 │
│ LOW_CONFIDENCE   │ 证据薄弱：因样本量极小、孤证或存在严重偏倚   │
└──────────────────┴────────────────────────────────────────────┘
```

---

## 2. 状态详细定义与审计判定准则

### 2.1 `NOT_REPORTED` (未报告 / 缺失)
- **判定标准**：检索文献正文、图表、附录及补充材料，均未找到该字段或参数的任何显式报告。
- **证据权重**：在综合分析与权重计算中，`NOT_REPORTED` 的有效证据权重**恒定为 0.0**。
- **处理红线**：严禁根据常识默认补填（如未报告对照组浓度时，不能脑补为 0 或生理盐水）。

### 2.2 `AMBIGUOUS` (存在歧义 / 条件不全)
- **判定标准**：原文提供了相关数值或陈述，但关键限定条件缺失（例如：“反应在微酸性环境下进行”，但未给出具体 pH 值；或者“准确率约 90%”，未说明是在验证集还是独立测试集上）。
- **处理策略**：如实截取原文，在 `notes` 中明确指出缺失的关键上下文，不得单方面假定具体数值。

### 2.3 `UNKNOWN` (科学界或作者认定未知)
- **判定标准**：作者在文献中明确指出该机制、副反应或长期效应“尚不清楚（remains unknown / to be elucidated）”，或由于技术限制无法观测。
- **处理策略**：标记为知识空白（Knowledge Gap），作为后续综述中“未来研究方向”或上游检索补齐任务的触发源。

### 2.4 `CONTRADICTORY` (篇内数据冲突 / 文本图表矛盾)
- **判定标准**：同篇文献的正文叙述与表格数据不一致，或摘要中结论与正文实测数据矛盾（常见于录入笔误或审查疏漏）。
- **处理策略**：同时记录相互冲突的两个数值及所在位置（例如：“正文第 4 页为 12.5 mg/L，Table 2 为 15.2 mg/L”），标记为 `CONTRADICTORY`，在人工仲裁前不强行采信任一方。

### 2.5 `LOW_CONFIDENCE` (证据薄弱 / 偏倚风险高)
- **判定标准**：虽然数据明确且由原文明示，但存在严重方法学缺陷（如无对照组、极小样本量 n=1、未控制关键混杂变量、或显著基准测试数据泄露）。
- **处理策略**：在提取表中保留原值，但降低其在综合分析中的证据权重，并在叙事综述中注明局限性。

## 3. 跨技能状态流转与下游映射

| 不确定性状态 | Discovery (检索层) 响应 | Extraction (抽取层) 处理 | Synthesis (综合层) 处理 |
|---|---|---|---|
| `NOT_REPORTED` | 若为关键纳入标准，考虑排除文献 | 状态记为 `NOT_REPORTED`，值填 `NR`，权重置 0 | 剔除出定量元分析，或触发 `EXTRACTION GAP` 补查附录 |
| `AMBIGUOUS` | 暂列为 `UNCERTAIN` 待复核 | 标记 `AMBIGUOUS` 并记录原文语句 | 放入敏感性分析，按保守边界隔离 |
| `UNKNOWN` | 触发相关假说追溯检索 | 记录为未决科学问题 | 归入 `KNOWLEDGE_GAPS` 章节 |
| `CONTRADICTORY` | 标记潜在存疑文献 | 标记 `CONTRADICTORY`，并列两套数据 | 提请审议，列入反方辩驳 (Devil's Advocate) 案例库 |
| `LOW_CONFIDENCE` | 正常收录但标注低评级 | 标记 `LOW_CONFIDENCE` 与偏倚类型 | 证据权重降权至 0.1~0.2，不可作为确立共识的支柱 |
