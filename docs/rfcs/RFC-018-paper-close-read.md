# RFC-018 独立单篇带读

状态：本地实现；首轮三篇真实文献与独立验收完成，后续已增加历史/文学两篇及五篇浏览器回归。独立技能通过仓库分发。

增加skills/paper-close-read：输入单篇全文，宿主模型写主线、翻译、白话和论证关系，确定性校验器与构建器生成离线单HTML。独立运行，不经过原四技能的检索/裁定执行门禁，也不自动触发它们；需要跨篇检索等任务时遵循对应流程。

兼容原schema v2和科学场景，保持既有视觉、字体、展开行为和批注锚点。新增按文章论证方式选读法、概念卡和可配置定量/编码/论证演示。核心不增加强制第三方依赖，PDF/JATS和模型能力明确区分。真实例子为定量、质性、概念论证三篇，输入、许可、HTML、重建和浏览器记录共同保留。既有科学例子做兼容回归。

验收：全文不丢块、每段有实际解释；三条路线连贯且演示原地可用；桌面/手机无关键交互故障；产物可重建一致；独立验收绑定候选摘要。学习效果未进行用户实验。
