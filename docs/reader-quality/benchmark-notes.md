# 成熟项目对照（2026-10-23，一手公开资料）

仅借鉴用户任务与交互原则，不复制其他项目代码、商业文案或服务；未试用付费账号的功能不标成实测。不同部署形态不做虚假优劣排名。

| 来源 | 直接支持的事实 | 本技能采用的方向 |
|---|---|---|
| [Zotero PDF Reader](https://www.zotero.org/support/pdf_reader) | 笔记中的批注保留引文及回原页入口；支持批注整理入笔记 | 让导出带着论文、引句、原页和位置，阅读中的取证不脱离上下文 |
| [Readwise Highlights/Notes](https://docs.readwise.io/reader/docs/faqs/highlights-tags-notes) | 键盘段落阅读、注释、整篇笔记和导出 | 增补不中断阅读的键盘操作与文档级笔记；保持可复制选区，不默认自动高亮 |
| [Readwise Basics](https://docs.readwise.io/reader/docs/faqs) | 离线阅读与命令面板 | 确定性离线操作、可发现的工具；不声称具有其云同步 |
| [Scholarcy Getting Started](https://help.scholarcy.com/) | 导入、阅读、整理、分析及导出的连续使用路径 | 完整任务闭环，不只生成一次摘要；不照搬闪卡为逐段解释 |
| [W3C Web Annotation Model](https://www.w3.org/TR/annotation-model/) | Annotation/SpecificResource和精确引文/位置选择器 | 提供标准格式导出，目标指向本派生阅读页的语义块，不能伪装已直接同步Zotero |
| [W3C APG Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) | 对话框名称、焦点进入/返回、Esc与模态键盘行为 | 所有对话框实际键盘验收，不靠添加role自称可访问 |
| [Semantic Reader研究](https://andrewhead.info/assets/pdf/semantic-reader.pdf) | 原地引用卡减少正文与书目来回定位的交互成本 | 证据预览与返回阅读位置；不能把高亮当作主线解释或保证学习成效 |
| [AllenAI doc2json](https://github.com/allenai/s2orc-doc2json) | 以不同解析入口处理PDF/TeX/JATS学术文档 | 清点原文结构和来源，不将一种提取器当成所有论文的正确性证明 |

Semantic Reader产品页抓取403，Scholarcy/features和Hypothesis旧帮助路径不可达；未据此推断功能不存在。上表可读的官方资料及作者论文作为依据。后续按实际缺陷扩展，不按竞品功能数量堆砌。
