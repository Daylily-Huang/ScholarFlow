# 文献阅读 skill v1.4.0 更新说明

状态：源码更新；本次不新建GitHub正式Release，不替换v1.3.0安装包。

- 白话按理解难度分配精力，难段选择具体推演、原句细读、材料对照或反例；不用统一问句和小数字模板。术语解释后可保留，不改变原文数量、概率或证据强度。
- 三分钟继续六步研究总览，关键量/基准按需呈现，先核对单位、分母、范围、时间与条件；可选metrics卡，不强造提升幅度。
- 十分钟逐节审读卡点、实际推进、所得与下一问题，做复述及删节检查，允许并列证据分支。
- 可为核心独立公式和主要表格配置解释记录，PDF保留其讲解与逻辑；LaTeX源码默认收起。
- 新增渐进带读入口与路线衔接按钮；英文始终显示，译文、白话、逻辑独立折叠且默认展开，检索可展开收起的匹配内容。
- 原图、原页窗口、笔记、备份和现有动画保留。现有10篇示例从原输入重建；论文原件、译文与来源JSON未因界面升级改写。

同一论文的稳定ID保留。旧HTML需重新生成才获得新界面；移动文件、换浏览器或升级阅读页前可先导出阅读备份。机器验证不代表真实人类三分钟理解效果。
