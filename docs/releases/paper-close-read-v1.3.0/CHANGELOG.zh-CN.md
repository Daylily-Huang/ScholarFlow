# 文献阅读 skill 1.3.0 中文更新说明

- **PDF原页窗口**：真实PDF页离线内嵌，可按可靠页码定位、翻页、缩放；标题栏拖动、右下角调整窗口大小、最大化/还原。未核实页码明确作浏览；原图放大窗也支持移动缩放。
- 新增独立原文图清单：图号、子图、图注、来源与图片SHA256映射。严格完整稿构建会拦截遗漏、错误映射和未核子图；JATS另按原XML核对图与graphics，PDF按实际逐页核对记录。
- 10分钟读懂支持在指定讲解段后直接显示完整原图，附“先看哪里／图说明什么”，保留原始英文图注，可原地放大；教学动图继续保留。
- JATS导入保留一幅图中的多个graphic及图像公式，不再只取第一张；段内未解析的图片标记直接报错，避免静默变成普通文字。
- 双语PDF继续保留正文全部原图/图像公式与图注，导读中的重复同图不另印一遍，来源与原图核对状态随PDF保留。
- Thomsen/Wilcox两篇真实示例完成独立图清单及对应讲解重建，组合图与子图完整保留，原文、图片字节和稳定ID不变。

旧资料兼容重建但无清单时明确“原图完整性待核对”。技术校验不能替代看原页，也不能自动证明子图内容与清晰度；来源或外部补充材料未拿到时如实标注范围，不宣称已完整。v1.2.0旧Release保留。
