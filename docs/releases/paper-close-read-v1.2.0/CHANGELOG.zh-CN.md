# 文献阅读 skill 1.2.0 中文更新说明

## 新增

- **双语 PDF 导出**：原文和中文译文左右对照，A4 横向或纵向，长段跨页并重复栏头；保留公式、原图表、逐段词汇与来源归属。可选白话、逻辑和附录。
- **直接生成 PDF 文件**：标准库脚本调用本地 Chrome/Chromium/Edge，隔离浏览器 profile，核验排版后生成，失败保留旧文件；也可从 HTML 打印窗口另存 PDF。
- **逐段重点词汇**：英文词或连续词组配本段中文义，不统一凑条数。输入校验拒绝原段不存在、重复或格式有误的条目。旧阅读资料继续兼容。
- **首页免克隆安装**：醒目的 Release 独立 ZIP 下载入口，解压复制或包内安装器均可使用。

- **白话讲解重新定准**：首选具体对象按简单规则推演，先直觉、后关键运作、按需说明边界；类比和失败场景服务当前卡点，禁止用未解释概念解释概念，不强行每段三层或统一条数。

## 保持

3 分钟六步总览、10 分钟主线与就地动图、逐段通俗白话及递进逻辑、默认展开、批注和阅读备份均继续提供。词汇是补充，不能替代讲解。

## 使用与边界

PDF 是静态对照文档，交互动图、阅读工具和批注仍在 HTML。长段按段对照，不声称逐行对齐。词汇释义由阅读资料编写并需核对；自动校验不能证明翻译正确。代码安装包不含论文全文、模型、OCR 服务或第三方浏览器。已有 HTML 需重建，更新前可备份阅读记录。
