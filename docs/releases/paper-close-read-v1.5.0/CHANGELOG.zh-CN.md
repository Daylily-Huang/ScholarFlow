# 文献阅读 skill v1.5.0 更新说明

状态：源码更新；本次不新建正式Release，不替换已发布v1.3.0安装包。

- 新增题材无关process绘制：由JSON对象、属性和关键帧编排移动、曲线、状态切换和标签；不需要为每个新主题新增专用Python/JS。新题材的设计、实现与验收由执行助手完成，使用者只需提供文献和目标。
- 新增visual_plan与--require-visual-plan，把主要理解难点映射到动图、原图、静图或文字，注明选择理由和观察目标。旧场景仍可复用，旧资料保持兼容。
- 验收从“有多少播放器”改为逐难点检查：复用只计一个；图文阶段、对象变化、关系箭头、证据强度和数值比较基准都需实际审读。文字/透明度切换不能代替过程；论证图不能冒充机制。
- 过程输入只接受有限绘图数据，不执行作者提供的JS、HTML、表达式或联网素材。结构校验不能证明解释充分或科学结论正确。
- 保留原图/原页、双语PDF、词汇、默认展开与独立折叠、笔记备份等现有功能。正式例页从原输入重建，不改源论文。

真实Ranc论文演示用于本地验收，原PDF和全文不随此次提交上传。
