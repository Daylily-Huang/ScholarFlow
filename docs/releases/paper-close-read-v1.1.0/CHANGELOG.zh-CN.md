# 文献阅读 skill 1.1.0 中文更新说明

发布日期：2026-10-23。组件标签：`paper-close-read-v1.1.0`。
这是文献阅读 skill 的独立组件版本，不改变 ScholarFlow 整体引擎的版本号。

## 这版能做什么

给 AI 助手一篇论文，制作可离线打开的 HTML 带读页；支持自然科学与人文社科，按实际论证组织讲解。

- **三分钟入门讲清整篇**：背景 → 已有缺口 → 核心问题 → 方法/材料与论证路径 → 主要结果 → 结论与意义。
- **十分钟沿主线讲通难点**：补出理解所需的中间步骤，抽象概念与过程的动图直接放在对应讲解下面，支持播放、暂停、拖动、分步和调速。
- **逐段白话与递进逻辑**：原文、译文、白话、逻辑默认展开；按文段的真实推理组织要点，不固定两条或三条。作者、单位等元信息简列。
- **阅读体验**：18px默认字号，可调16/18/20px；搜索前后定位、查看证据后返回、原图放大、回到顶部、打印展开，以及继续上次阅读位置。
- **笔记与恢复**：三条路线可高亮批注，支持误删撤销、整篇笔记、完整JSON备份/合并导入、Markdown和标准批注导出。修复写入失败后遇到其他窗口更新时可能丢失未保存批注的问题。
- **制作与维护**：补充来源清点、主线与新手难点写作、图文规划和实际审读流程；错误输入给出定位提示，失败构建保留已有HTML；安装先校验再替换。

## 安装与升级

优先下载本Release的 `paper-close-read-v1.1.0.zip`，按附件 `INSTALL.zh-CN.md` 操作。ZIP内已附安装器、说明和文件哈希清单，不需要下载整个仓库。不要把GitHub自动生成的Source code ZIP当作此独立安装包。

从旧版升级不会自动重写已有HTML。重要批注先导出完整JSON备份；重新生成阅读页时保留原文件，避免混淆版本和浏览器存储位置。
