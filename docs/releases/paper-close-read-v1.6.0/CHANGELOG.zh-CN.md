# 文献阅读 skill v1.6.0 中文更新说明

本次重点是来源保真、讲解与动画相邻、新稿完整检查及可靠安装。验证范围见 [验收说明](VALIDATION.zh-CN.md)。

- 新稿默认完整检查，旧资料兼容重建与待补稿分别标识，避免漏开严格选项后误称已验收。
- 无小标题论文可加明确标识为整理者添加的阅读分段，保留原文顺序、ID与批注定位。
- JATS独立清点所有图像，包括图像表格、行内图；保留混合引文、诗行、强调和出处。非图像MathML/TeX公式明确停止，待核对转录，不再静默压平。
- 重复导入拒绝覆盖已有转录和审读记录；导入文件成组成功写入，失败撤回本次新文件。
- 十分钟动图可通过after精确跟随解释段落，不需切碎故事。
- 独立安装包采用带备份的升级器；按来源清单定位转录文件，不硬编码source.md。只有包内来源确与提交相同才记录source_commit，否则明确working-tree，正式打包可用--require-committed拒绝未提交候选。
- 更新过时的版本/打印说明；软件边界回归、真实示例重建和内容审读分别报告，不把测试通过等同于三分钟学会或翻译全对。

本版不承诺自动判断译名、段落主题或学术推断的全部语义；必须保留原页核查与面向实际读者的审读。已有HTML需重建才获得改动，旧例兼容重建不冒充按当前完整新稿重新撰写。
